Appendix A — Program assembly maps

The main chapters explain why Literate is designed as it is and show the fragments that realize each idea. This appendix records how those fragments are gathered into complete generated files. These roots are essential to tangling the program, but their ordering is mechanical rather than part of the main argument.

A root below can be read as a compact table of contents for one generated module. Its child names point back to the chapters where the corresponding ideas are explained. Readers can use this map to move between a complete file and the ideas from which it is assembled.
