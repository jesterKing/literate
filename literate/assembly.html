Appendix A — Program assembly maps

The main chapters explain why Literate is designed as it is and show the fragments that realize each idea. This appendix records how those fragments are gathered into complete generated files. These roots are essential to tangling the program, but their ordering is mechanical rather than part of the main argument.

A root below can be read as a compact table of contents for one generated module. Its child names point back to the chapters where the corresponding ideas are explained. Readers can use this map to move between a complete file and the ideas from which it is assembled.

The browser bundle installs Mermaid and its explicitly supported extensions into one offline runtime.

<<assemble the offline Mermaid browser.*>>= src/publication-mermaid-browser.mjs $
import mermaid from 'mermaid/dist/mermaid.esm.mjs';
import zenuml from '@mermaid-js/mermaid-zenuml/dist/mermaid-zenuml.esm.mjs';
import tidyTree from '@mermaid-js/layout-tidy-tree';
const offlineZenuml = { ...zenuml, loader: async () => {
    const existingStyles = new Set(document.querySelectorAll('style'));
    const definition = await zenuml.loader();
    const bundledFont = '@font-face{font-family:MS Sans Serif;src:url(/fonts/MS%20Sans%20Serif.ttf) format("truetype")}';
    for (const style of document.querySelectorAll('style')) {
        if (!existingStyles.has(style) && style.textContent.includes(bundledFont)) {
            style.textContent = style.textContent.replaceAll(bundledFont, '');
        }
    }
    return definition;
} };
mermaid.registerLayoutLoaders(tidyTree);
globalThis.mermaid = mermaid;
globalThis.publicationMermaidReady = mermaid.registerExternalDiagrams([offlineZenuml]);
