Code actions

Missing-fragment diagnostics carry a stable code rather than relying on their human-readable message. Quick fixes refresh the read-only repository, then require an exact unresolved reference in the current source snapshot. Cancelled requests and buffers changed during refresh return no actions.

The edit belongs to the requested document URI, not the active editor. It adds an empty definition after the containing, closed top-level fragment fence. Unsafe insertion sites (including nested or unclosed fences) are declined rather than invoking the active-editor create command. VS Code applies the proposed edit; this provider neither applies edits nor generates output. Tilde fences permit backticks in fragment names and language identifiers without breaking the header.

Match a stable source snapshot

Filter diagnostics before refreshing the repository, then verify both the requested buffer and any open copy against the captured text and version. The repository's source must agree too: an action derived from stale occurrences could edit the wrong range. These checks share the method's scope without adding an async boundary.

<<code action snapshot validation>>= 
const diagnostics = context.diagnostics.filter(diag =>
    (typeof diag.code === 'object' ? diag.code.value : diag.code) === 'missing-fragment');
if(token.isCancellationRequested || !diagnostics.length ||
    (context.only && !context.only.contains(vscode.CodeActionKind.QuickFix))) { return []; }
const folder = determineWorkspaceFolder(document);
if(!folder) { return []; }
const version = document.version;
const text = document.getText();
await this.repository.processLiterateFiles(document);
if(token.isCancellationRequested || document.version !== version || document.getText() !== text) { return []; }
const documentPath = path.posix.relative(folder.uri.path, document.uri.path);
const sources = this.repository.getSourceDocuments(folder);
if(sources.find(source => source.path === documentPath)?.text !== text ||
    vscode.workspace.textDocuments.some(open => open.uri.toString() === document.uri.toString() &&
        (open.version !== version || open.getText() !== text))) { return []; }

Require an exact reference and a safe insertion site

One fix per unresolved name is enough. Wildcard roots and already-defined names are not creation candidates. Matching source text guards the diagnostic range; checking a closed, top-level fence ensures insertion cannot capture existing prose or code. Re-parsing the proposed header protects fragment identity.

<<code action unresolved reference and insertion site>>= 
const reference = occurrences.find(item => item.path === documentPath && item.kind === 'reference' &&
    item.line === diagnostic.range.start.line && item.column === diagnostic.range.start.character);
if(!reference || offered.has(reference.name) || reference.name.endsWith('.*') ||
    occurrences.some(item => item.name === reference.name && item.kind === 'definition')) { continue; }
const range = new vscode.Range(reference.line, reference.column, reference.line, reference.endColumn);
if(document.getText(range) !== `${OPENING}${reference.name}${CLOSING}`) { continue; }
const usage = this.repository.getTokenAtPosition(document, range).token;
if(!usage || usage.type !== 'fence' || !usage.map || usage.level !== 0) { continue; }
const header = parseFragmentHeader(usage.info);
const closing = document.lineAt(usage.map[1] - 1).text.trim();
if(!header || !/^(`{3,}|~{3,})$/.test(closing) || closing[0] !== usage.markup[0] ||
    closing.length < usage.markup.length) { continue; }
const info = `${header.language} : ${OPENING}${reference.name}${CLOSING}=`;
if(parseFragmentHeader(info)?.name !== reference.name) { continue; }

Offer the edit without applying it

Preserve the document's line ending and attach the edit to its URI, even if another editor is active. Only a fully constructed action marks a name as offered; VS Code retains responsibility for applying the edit and presenting its diagnostic.

<<code action proposed edit>>= 
const eol = document.eol === vscode.EndOfLine.CRLF ? '\r\n' : '\n';
const position = usage.map[1] < document.lineCount ? new vscode.Position(usage.map[1], 0)
    : document.positionAt(text.length);
const edit = new vscode.WorkspaceEdit();
edit.insert(document.uri, position, `${eol}~~~ ${info}${eol}~~~${eol}`);
const action = new vscode.CodeAction(`Create fragment for ${OPENING}${reference.name}${CLOSING}`,
    vscode.CodeActionKind.QuickFix);
action.diagnostics = [diagnostic];
action.edit = edit;
actions.push(action);
offered.add(reference.name);
