Command-line generation

This chapter is authoritative for src/cli.ts and src/cli-entry.ts. The CLI adapts files and terminal output to the shared engine; it does not implement a second fragment language. Its entry point assembles a command from argument parsing, project loading, validation, and an explicit read-only or writing operation.

Commands and their boundaries

Run yarn literate <command> to build the CLI independently of the extension and execute it. To reuse a known-working build while editing generated code, invoke node out/cli-entry.js <command> directly.

  • inspect identifies documents, templates, fragment declarations, and references. It uses the engine's parser metadata, including partial metadata on invalid input.
  • generate validates the whole project before writing changed source and HTML.
  • check compares the generation plan with disk without writing.
  • latex explicitly exports one LaTeX book through Pandoc, without source/HTML generation, TeX execution, or PDF compilation.
  • pdf explicitly compiles the same book in a private build directory and writes only the requested PDF. --keep-build retains that directory for inspection. It never generates source or HTML first, downloads tools, or runs automatically.
  • self-check additionally type-checks fresh generated sources and rebuilds the engine to verify a fixed point. It executes this repository's trusted code; it is not a sandbox or a command for arbitrary untrusted projects.

All commands accept an optional project root and --json. --help, -h, and help <command> explain usage. Success exits 0; invalid input, I/O failures, stale checks, and failed verification exit 1; usage errors exit 2. An empty project fails rather than passing vacuously.

A machine-readable result

JSON mode emits exactly one object to stdout, including on usage and I/O errors. Human progress and error messages are suppressed in that mode. schemaVersion provides a compatibility boundary for scripts and AI tools. Diagnostic and inspection coordinates are zero-based; human diagnostic messages add one to both. Filesystem preflight

A missing file is expected during generation. Other failures, including access errors, must propagate rather than being mistaken for absent output.

<<cli missing file predicate>>=
function missing(error: unknown): boolean {
    return (error as NodeJS.ErrnoException).code === 'ENOENT';
}

All adapter paths pass through the engine's portable path policy before reaching the filesystem. This also normalizes paths before collision checks.

<<cli relative path validation>>=
function relative(value: string): string {
    const normalized = safeRelativePath(value);
    if (!normalized) { throw new Error(`Invalid relative path: ${value}`); }
    return normalized;
}

Lexical validation cannot detect symlinks. Walk each existing component and reject links, non-directory ancestors, and non-file targets, even when a link stays inside the project. A missing ancestor means the target is absent; it is not created until all targets have passed preflight.

<<cli filesystem inspection>>=
async function inspect(root: string, value: string): Promise<boolean> {
    const parts = relative(value).split('/');
    let current = root;
    for (let index = 0; index < parts.length; index++) {
        current = path.join(current, parts[index]);
        let stat;
        try { stat = await fs.lstat(current); }
        catch (error) {
            if (missing(error)) { return false; }
            throw error;
        }
        if (stat.isSymbolicLink()) { throw new Error(`Symbolic link is not allowed: ${value}`); }
        if (index < parts.length - 1) {
            if (!stat.isDirectory()) { throw new Error(`Parent is not a directory: ${value}`); }
        } else if (!stat.isFile()) {
            throw new Error(`Target is not a regular file: ${value}`);
        }
    }
    return true;
}

Transaction filesystem boundary

The adapter validates the trusted root and every existing path component with lstat, including dangling links. Operations are exclusive or nonrecursive. Node has no portable no-replace rename: destination inspection followed by fs.rename prevents ordinary overwrites, but cannot close the race with another writer. Callers must serialize generation and exclude external filesystem changes. This is exception recovery, not crash durability or simultaneous atomic visibility.

Reading an existing output records its POSIX permission bits. Before installing its stage we apply those bits, preserving executable/read-only modes on local POSIX filesystems. Ownership, ACLs and remote-provider permissions are not guaranteed. Recovery stages/backups have numbered names without a .literate suffix, so crash residue is not discovered as source. Never blindly delete reported recovery paths.

Establish a trusted directory before classifying a target

Every inspection rechecks the root rather than relying on an earlier preflight. The normalized components feed the walk below; neither root symlinks nor a non-directory root can be treated as a missing destination.

<<cli transaction root inspection>>=
const parts = relative(value).split('/');
const rootStat = await fs.lstat(root);
if (rootStat.isSymbolicLink() || !rootStat.isDirectory()) {
    throw new Error(`Root is not a regular directory: ${root}`);
}

The walk distinguishes files, directories, and absence for the transaction coordinator. Only absence is recoverable here; links and special files are errors. Returning at the first missing component permits later staged creation without creating anything during inspection.

<<cli transaction component inspection>>=
let current = root;
for (const [index, part] of parts.entries()) {
    current = path.join(current, part);
    let stat;
    try { stat = await fs.lstat(current); }
    catch (error) {
        if (missing(error)) { return 'missing'; }
        throw error;
    }
    if (stat.isSymbolicLink()) { throw new Error(`Symbolic link is not allowed: ${value}`); }
    if (index < parts.length - 1) {
        if (!stat.isDirectory()) { throw new Error(`Parent is not a directory: ${value}`); }
    } else {
        if (stat.isFile()) { return 'file'; }
        if (stat.isDirectory()) { return 'directory'; }
        throw new Error(`Target is not a regular file or directory: ${value}`);
    }
}
throw new Error(`Invalid relative path: ${value}`);

Carry permissions from the original to its replacement

Reading records mode bits under the normalized destination, not the temporary stage name. The byte snapshot and permission snapshot belong to the same adapter instance and remain available during installation or recovery.

<<cli transaction read with permissions>>=
async read(value) {
    if (await inspectPath(value) !== 'file') { throw new Error(`Not a file: ${value}`); }
    const stat = await fs.lstat(target(value));
    const bytes = await fs.readFile(target(value));
    modes.set(relative(value), stat.mode & 0o7777);
    return bytes;
},

Create without replacing existing entries

Both creation operations require an absent path. File creation also uses the filesystem's exclusive flag; directory creation is deliberately nonrecursive so the coordinator can track exactly which directories it owns.

<<cli transaction exclusive creation>>=
async mkdir(value) {
    if (await inspectPath(value) !== 'missing') { throw new Error(`Path exists: ${value}`); }
    await fs.mkdir(target(value));
},
async writeNew(value, content) {
    if (await inspectPath(value) !== 'missing') { throw new Error(`Path exists: ${value}`); }
    await fs.writeFile(target(value), content, { flag: 'wx' });
},

Install a stage using the destination's remembered mode

A rename requires a regular source and absent destination. Only stage files inherit the destination's saved mode, leaving backup moves unchanged. The inspection/rename race remains subject to the serialization contract above.

<<cli transaction rename with permissions>>=
async rename(from, to) {
    if (await inspectPath(from) !== 'file') { throw new Error(`Not a file: ${from}`); }
    if (await inspectPath(to) !== 'missing') { throw new Error(`Path exists: ${to}`); }
    const mode = modes.get(relative(to));
    if (from.endsWith('.stage') && mode !== undefined) { await fs.chmod(target(from), mode); }
    await fs.rename(target(from), target(to));
},

Remove only the expected entry kind

Cleanup revalidates each recovery path. Nonrecursive directory removal refuses to erase unexpected contents, allowing the coordinator to report recoverable residue rather than broadening the cleanup operation.

<<cli transaction removal>>=
async removeFile(value) {
    if (await inspectPath(value) !== 'file') { throw new Error(`Not a file: ${value}`); }
    await fs.unlink(target(value));
},
async removeDirectory(value) {
    if (await inspectPath(value) !== 'directory') { throw new Error(`Not a directory: ${value}`); }
    await fs.rmdir(target(value));
},

Discover saved inputs

Directory enumeration is sorted, skips symlinks, and shares exclusions with the editor. A nested manifest, or an immediate directory containing one, establishes a series boundary so sibling project roots are not absorbed by legacy discovery. The engine will apply index ordering later. The CLI reads disk, not unsaved editor buffers, so CLI and editor generation must not run concurrently against the same project.

<<cli document discovery>>=
async function discover(root: string): Promise<SourceDocument[]> {
    const documents: SourceDocument[] = [];
    const visit = async (directory: string): Promise<void> => {
        const entries = await fs.readdir(path.join(root, directory), { withFileTypes: true });
        if (directory && entries.some(entry => entry.isFile() && entry.name === publicationWorkspaceManifest)) {
            return;
        }
        if (directory) {
            for (const entry of entries) {
                if (entry.isDirectory() && !entry.isSymbolicLink() &&
                    await inspect(root, `${directory}/${entry.name}/${publicationWorkspaceManifest}`)) { return; }
            }
        }
        entries.sort((a, b) => a.name < b.name ? -1 : a.name > b.name ? 1 : 0);
        for (const entry of entries) {
            if (entry.isSymbolicLink()) { continue; }
            const name = directory ? `${directory}/${entry.name}` : entry.name;
            if (entry.isDirectory()) {
                if (!excluded.has(entry.name)) { await visit(name); }
            } else if (entry.isFile() && entry.name.endsWith('.literate')) {
                const normalized = relative(name);
                if (!await inspect(root, normalized)) { throw new Error(`Source disappeared: ${name}`); }
                documents.push({ path: normalized, text: await fs.readFile(path.join(root, normalized), 'utf8') });
            }
        }
    };
    await visit('');
    return documents;
}

Complete publication snapshots

A supplied snapshot replaces discovery; it is not an overlay. The caller must include every source, including chapters excluded from publication, so input protection remains complete. Copy validated records before any asynchronous work can observe caller mutation. Templates are enumerated for protection, not read as text by either publication command.

<<cli document discovery>>=+
function validateSnapshot(documents: readonly SourceDocument[]): SourceDocument[] {
    if (!Array.isArray(documents)) { throw new Error('Invalid document snapshot'); }
    const seen = new Set<string>();
    return documents.map(document => {
        if (!document || typeof document.path !== 'string' || typeof document.text !== 'string') {
            throw new Error('Invalid snapshot document');
        }
        const normalized = safeRelativePath(document.path);
        if (!normalized || normalized !== document.path || document.path.split('/').includes('..')
            || !normalized.endsWith('.literate')) {
            throw new Error(`Invalid snapshot path: ${document.path}`);
        }
        const key = normalized.toLowerCase();
        if (seen.has(key)) { throw new Error(`Duplicate snapshot path: ${normalized}`); }
        seen.add(key);
        return { path: normalized, text: document.text };
    });
}

Explicit LaTeX export

latex [root] --output books/book.tex resolves the destination relative to the selected project root (the current directory if omitted), never relative to a source chapter. Absolute paths, parent traversal, and non-.tex destinations are usage errors. Options take separate values, not --name=value. Paper defaults to a4, margin to 20mm. The existing root index.literate SETTINGS theme key selects the publication palette through resolveProjectTheme; invalid themes report its diagnostics before conversion. Decimal millimetres are the only accepted margin unit, subject to the renderer's page/body constraints. --margin-top, --margin-right, --margin-bottom, and --margin-left override physical sides in a one-sided book. --margin-inner and --margin-outer instead select mirrored, two-sided pages; they cannot be combined with left/right. Each unspecified side falls back to --margin, or 20mm when it is omitted.

The renderer automatically resolves font settings from the root index.literate SETTINGS through its publication-settings dependency. There are no font CLI flags. Export does not install or bundle fonts. The resolved families and the template's TeX packages are dependencies for later compilation by the user, not prerequisites checked or installed by this command.

A bounded production converter

runPandoc implements the injected LatexConverter contract. Only the fixed executable pandoc on PATH is spawned, with an argument array and no shell. JSON is sent on stdin; neither source nor output paths become process arguments. The converter produces a body, never a standalone preamble or PDF. A 30-second wall-clock deadline includes stdin delivery and pipe closure. Stdout is limited to 16 MiB and stderr to 64 KiB; exceeding either fails rather than truncating a successful book. Process failures occur before the transaction boundary.

<<cli Pandoc runner>>=
export const runPandoc: LatexConverter = async document => {
    const input = JSON.stringify(document);
    return new Promise<string>((resolve, reject) => {
        const child = spawn('pandoc', [

        ], { shell: false, stdio: ['pipe', 'pipe', 'pipe'] });
        const stdout: Buffer[] = [], stderr: Buffer[] = [];
        let outputBytes = 0, errorBytes = 0;
        let settled = false;
        let inputError: Error | undefined;
        <<cli Pandoc completion>>

        const signals = ['SIGINT', 'SIGTERM', 'SIGHUP'] as const;

        for (const signal of signals) { process.on(signal, interrupted); }

        child.stdin.end(input);

Diagnostics retain at most 2 KiB of stderr, remove terminal escape sequences and control characters, and collapse whitespace for both human and JSON consumers. On failure, kill the direct child and close its pipes without waiting indefinitely for inherited descriptors. This is resource bounding, not a process sandbox.

<<cli Pandoc completion>>=
const detail = (): string => Buffer.concat(stderr).toString('utf8').slice(0, 2048)
    .replace(/\x1b\[[0-?]*[ -/]*[@-~]/g, '')
    .replace(/[\u0000-\u001f\u007f-\u009f]/g, ' ').replace(/\s+/g, ' ').trim();
const complete = (error?: Error): void => {
    if (settled) { return; }
    settled = true;
    clearTimeout(timer);
    for (const signal of signals) { process.removeListener(signal, interrupted); }
    if (error) {
        child.kill('SIGKILL');
        child.stdin.destroy(); child.stdout.destroy(); child.stderr.destroy();
        const diagnostic = detail();
        reject(new Error(error.message + (diagnostic ? `: ${diagnostic}` : '')));
    } else { resolve(Buffer.concat(stdout).toString('utf8')); }
};

Count bytes before retaining chunks. Pipe errors are handled explicitly; a stdin error is reported after process closure so an early Pandoc rejection can retain its more useful exit status and stderr. The deadline still covers a stalled child.

<<cli Pandoc streams>>=
child.stdout.on('data', (chunk: Buffer) => {
    if (settled) { return; }
    outputBytes += chunk.length;
    if (outputBytes > 16 * 1024 * 1024) { complete(new Error('Pandoc stdout exceeded 16 MiB')); }
    else { stdout.push(chunk); }
});
child.stderr.on('data', (chunk: Buffer) => {
    if (settled) { return; }
    errorBytes += chunk.length;
    const remaining = 64 * 1024 - (errorBytes - chunk.length);
    if (remaining > 0) { stderr.push(chunk.subarray(0, remaining)); }
    if (errorBytes > 64 * 1024) { complete(new Error('Pandoc stderr exceeded 64 KiB')); }
});
child.stdin.on('error', error => { inputError = error; });
child.stdout.on('error', error => complete(error));
child.stderr.on('error', error => complete(error));

async function protectLatexAliases(root: string, inputs: string[], outputs: string[],
    browser?: { path: string; stat: { dev: number; ino: number } }): Promise<void> {
    const identities = new Map<string, string>();
    if (browser) { identities.set(`${browser.stat.dev}:${browser.stat.ino}`, browser.path); }
    for (const input of inputs) {
        if (!await inspect(root, input)) { continue; }
        const stat = await fs.stat(path.join(root, input));
        identities.set(`${stat.dev}:${stat.ino}`, input);
    }
    const seen: string[] = [];
    for (const output of outputs) {
        const name = output.toLowerCase();
        if (seen.some(other => name === other || name.startsWith(other + '/') || other.startsWith(name + '/'))) {
            throw new Error(`LaTeX outputs conflict: ${output}`);
        }
        seen.push(name);

        const key = `${stat.dev}:${stat.ino}`;
        if (identities.has(key)) { throw new Error(`LaTeX output aliases input/output: ${output} (${identities.get(key)})`); }

A PDF invocation naming a manifest directory and no publication is a series publication. Resolve every project root and PDF from the manifest directory, rejecting symbolic links in all existing components. Plan and compile in manifest order, but do not mutate the filesystem until every publication succeeds. The final PDFs then enter one transaction rooted at the filesystem root; transaction paths are canonical absolute destinations with the leading separator removed, while protocol paths remain manifest-relative. This permits declared outputs next to or above project roots without weakening path inspection.

<<cli LaTeX plan>>=+
async function regularDirectory(root: string, value: string, label: string): Promise<string> {
    let current = root;
    for (const component of value.split('/')) {
        if (!component || component === '.') { continue; }
        current = path.resolve(current, component);
        const stat = await fs.lstat(current);
        if (stat.isSymbolicLink() || !stat.isDirectory()) { throw new Error(`${label} is not a regular directory: ${value}`); }
    }
    return current;
}

            warnings.push(...built.warnings.map(value => `${publication.id}: ${value}`));
            if (built.buildDirectory) { buildDirectories.push(built.buildDirectory); }
            if (built.pageLabels) { nextPages.set(publication.id, built.pageLabels); } else { completePages = false; }
            roundFiles.push({ path: plan.transactionPath, content: built.pdf, display: publication.pdf! });
        } catch (error) {
            const details = error as Partial<PdfCompilationError>;
            warnings.push(...(details.warnings ?? []).map(value => `${publication.id}: ${value}`));
            if (details.buildDirectory) { buildDirectories.push(details.buildDirectory); }
            response.publication = { warnings, ...(buildDirectories.length === 1
                ? { buildDirectory: buildDirectories[0] } : {}) };
            throw error;
        }

        compiledFiles = roundFiles;
        if (!completePages) { break; }
        const stable = round > 0 && JSON.stringify([...pageMaps]) === JSON.stringify([...nextPages]);
        pageMaps = nextPages;
        if (stable) { break; }
        if (round === 3) { throw new Error('Cross-publication page references did not converge'); }
    }
    response.publication = { warnings, ...(buildDirectories.length === 1 ? { buildDirectory: buildDirectories[0] } : {}) };
    if (!json) { for (const warning of warnings) { io.stderr(`literate: warning: ${warning}\n`); } }
    const filesystemRoot = path.parse(plans[0].output).root;
    const statuses = new Map<string, CliResponse['outputs'][number]>();

        const exists = await inspect(filesystemRoot, file.path);
        const current = exists && (await fs.readFile(path.join(filesystemRoot, file.path))).equals(Buffer.from(file.content));
        const output = { path: file.display, status: current ? 'current' as const : exists ? 'stale' as const : 'missing' as const };
        response.outputs.push(output); statuses.set(file.path, output);
    }
    checkCancelled?.();
    const written = await commitOutputs(compiledFiles.map(file => ({ path: file.path, content: file.content })),
        transactionIO(filesystemRoot), checkCancelled);
    for (const pathname of written) { const output = statuses.get(pathname); if (output) { output.status = 'written'; } }
    if (!json) { for (const output of response.outputs) { if (output.status === 'written') { io.stdout(`generated: ${output.path}\n`); } } }
    return finish(0);
}

            io.stderr(`${diagnostic.path}:${diagnostic.line + 1}:${diagnostic.column + 1}: ${diagnostic.message}\n`);
        }
    }
    return finish(1);
}
if (command === 'inspect') { return finish(0); }

Compile only the private publication plan

The virtual entry and companions are compiler inputs, not project destinations. Only the final PDF is protected against project inputs and passed to the output transaction. An unrelated project book.tex is neither inspected nor replaced. Retained directories and compiler warnings remain visible even when compilation fails; JSON consumers receive them separately from the error message. Record compiler progress before checking cancellation so a completed private build is still reported even when its PDF must not be published.

<<cli compile PDF>>=
if (command === 'pdf') {
    const publication = (details: { warnings?: string[]; buildDirectory?: string }): void => {
        response.publication = { warnings: details.warnings ?? [],
            ...(details.buildDirectory === undefined ? {} : { buildDirectory: details.buildDirectory }) };
        if (!json) {
            for (const warning of response.publication.warnings) { io.stderr(`literate: warning: ${warning}\n`); }
            if (details.buildDirectory !== undefined) { io.stderr(`literate: build directory: ${details.buildDirectory}\n`); }
        }
    };
    checkCancelled?.();
    try {
        const compiled = await compile(result.files, entry, { keepBuild: flags.has('--keep-build'), checkCancelled });
        publication(compiled);
        result.files = [{ path: latexOutput, content: compiled.pdf }];
    } catch (error) {
        if (error instanceof Error) { publication(error as Partial<PdfCompilationError>); }
        throw error;
    }
    checkCancelled?.();
}

Validate the complete destination set

A file cannot also be a directory containing another output. Retain this adapter check in addition to engine validation so preflight remains explicit before any filesystem mutation.

<<cli validate output destinations>>=
const files = result.files.map(file => ({ path: relative(file.path), content: file.content }));
const targets = new Set<string>();
for (const file of files) {
    if (targets.has(file.path)) { throw new Error(`Duplicate output: ${file.path}`); }
    targets.add(file.path);
}
for (const target of targets) {
    const parts = target.split('/');
    for (let index = 1; index < parts.length; index++) {
        const parent = parts.slice(0, index).join('/');
        if (targets.has(parent)) { throw new Error(`Output is also a parent directory: ${parent}`); }
    }
}

Compare before creating anything

Every target passes filesystem inspection before the first write or directory creation. Compare bytes rather than timestamps. Keep a reference to each status entry so a completed write can change only that entry to written.

<<cli compare output bytes>>=
const changes: { path: string; content: string | Uint8Array; output: CliResponse['outputs'][number] }[] = [];
for (const file of files) {
    const exists = await inspect(root, file.path);
    const content = typeof file.content === 'string' ? Buffer.from(file.content, 'utf8') : Buffer.from(file.content);
    const status: OutputStatus = !exists ? 'missing'
        : (await fs.readFile(path.join(root, file.path))).equals(content) ? 'current' : 'stale';
    const output = { path: file.path, status };
    response.outputs.push(output);
    if (status !== 'current') { changes.push({ ...file, output }); }
}

Read-only verification

Both checks reject stale output. Self-host verification is loaded only after that check passes, and its named stages are retained in JSON or printed for a human. It type-checks fresh sources and executes a rebuilt engine in a child process; it does not claim to test the rebuilt CLI's runtime behavior.

<<cli read-only checks>>=
if (command === 'check' || command === 'self-check') {
    if (!json) {
        for (const change of changes) { io.stdout(`${change.output.status}: ${change.path}\n`); }
    }
    if (changes.length) { return finish(1); }
    if (command === 'self-check') {
        const { verifySelfHosting } = await import('./self-hosting');
        response.selfHosting = await verifySelfHosting(root, documents, templates, files.map(file => {
            if (typeof file.content !== 'string') { throw new Error('Self-hosting requires text outputs'); }
            return { path: file.path, content: file.content };
        }));
        if (!json) {
            for (const check of response.selfHosting.checks) {
                io.stdout(`${check.ok ? 'ok' : 'failed'}: ${check.name}${check.message ? ': ' + check.message : ''}\n`);
            }
        }
        return finish(response.selfHosting.ok ? 0 : 1);
    }
    return finish(0);
}

Write changed outputs

Recheck the entire candidate set, including unchanged targets, through the shared transaction coordinator before mutation. Only changed bytes are staged and installed. Report written only after the complete batch commits. A committed cleanup failure still marks installed outputs, but fails the command and reports recovery locations. Other failures never claim writes succeeded. Obsolete outputs are not deleted.

The publication checkpoint is checked before writes and by the coordinator around preflight, after preparation, and after installation while rollback is still possible. Do not check cancellation after the coordinator returns: signals during irreversible cleanup cannot uncommit the publication. Report success or the coordinator's committed cleanup error instead, keeping signal handlers installed until it settles.

<<cli write changed outputs>>=
const markWritten = (paths: readonly string[]): void => {
    const written = new Set(paths);
    for (const output of response.outputs) {
        if (!written.has(output.path)) { continue; }
        output.status = 'written';
        if (!json) { io.stdout(`generated: ${output.path}\n`); }
    }
};
checkCancelled?.();
try {
    const written = await commitOutputs(files.map(file => ({
        path: file.path, content: typeof file.content === 'string' ? Buffer.from(file.content, 'utf8') : file.content
    })), transactionIO(root), checkCancelled);
    markWritten(written);
} catch (error) {
    if (error instanceof OutputTransactionError && error.committed) {
        markWritten(error.changedPaths);
    }
    throw error;
}
return finish(0);
