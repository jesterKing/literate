Publication font settings

This chapter owns src/publication-settings.ts and its headless tests. It reads only root index.literate SETTINGS tokens from a ParsedProject; parseProject has already canonicalized paths with safeRelativePath. Chapter settings and unrelated keys (including theme) are not ours. Keys and on/off are case-sensitive.

Code defaults to Lilex Nerd Font, whose regular, bold, italic and bold-italic files all report that exact family via fc-scan. Native italic faces avoid requiring synthesis for the default code comments.

This is typography selection, not font bundling. There is no filesystem access, font lookup, global installation, or runtime dependency. Renderers remain responsible for applying the selected families, sizes, and ligature policy. In particular, off calls for disabling calt (-calt), verified for the actual D2 font, rather than merely disabling liga. Body, code, and rail sizes are TeX points; diagram size is a CSS-pixel input to the isolated Mermaid renderer.

Public contract

All five families are resolved strings. Omitted notes inherit the final selected body family, whereas fragments default independently to Monofur. Four numeric roles retain compatibility defaults and their renderer-specific units: body, block code, and the publication rail use TeX points, while Mermaid uses CSS pixels. Diagnostics here describe settings only: they do not copy project.diagnostics. Callers must still gate rendering on source diagnostics through preparation (preparePandoc); a settings result alone is not permission to render. Source NUL rejection belongs to the existing parser, before Markdown can replace NUL with a replacement glyph.

import type { GenerationDiagnostic, ParsedProject } from './engine';

export interface PublicationFonts {
    body: string;
    heading: string;
    code: string;
    fragment: string;
    note: string;
}
export interface PublicationFontSizes {
    body: number;
    code: number;
    diagram: number;
    rail: number;
}
export const publicationFontSizeBounds = {
    body: { minimum: 8, maximum: 24, defaultValue: 11 },
    code: { minimum: 6, maximum: 24, defaultValue: 10 },
    diagram: { minimum: 8, maximum: 48, defaultValue: 16 },
    rail: { minimum: 7, maximum: 14, defaultValue: 9 }
} as const;
export interface PublicationSettingsResult {
    fonts: PublicationFonts;
    fontSizes: PublicationFontSizes;
    codeLigatures: boolean;
    diagnostics: GenerationDiagnostic[];
}

Scan in authored order

Each call starts fresh. A missing root is valid and yields defaults. We consume the existing fence tokens, including fences inside Markdown containers, without reparsing source or treating ordinary code blocks as settings.

<<publication settings resolver>>=
export function resolvePublicationSettings(project: ParsedProject): PublicationSettingsResult {
    const fonts: PublicationFonts = {
        body: 'Latin Modern Roman', heading: 'Monofur Nerd Font',
        code: 'Lilex Nerd Font', fragment: 'Monofur Nerd Font', note: ''
    };
    const fontSizes: PublicationFontSizes = {
        body: publicationFontSizeBounds.body.defaultValue,
        code: publicationFontSizeBounds.code.defaultValue,
        diagram: publicationFontSizeBounds.diagram.defaultValue,
        rail: publicationFontSizeBounds.rail.defaultValue
    };
    let codeLigatures = true;
    let explicitNote = false;
    const diagnostics: GenerationDiagnostic[] = [];
    const document = project.documents.find(value => value.path === 'index.literate');
    for (const token of document?.tokens ?? []) {
        if (token.type !== 'fence' || token.info.trim() !== 'SETTINGS') { continue; }
        token.content.split('\n').forEach((line: string, index: number) => {
            const match = /^\s*(font-body|font-heading|font-code|font-fragment|font-note|font-code-ligatures|font-size-body|font-size-code|font-size-diagram|font-size-rail)\s*=(.*)$/.exec(line);
            if (!match) { return; }
            const key = match[1];
            const value = match[2].trim();

Family values use the same simple ASCII grammar as the existing LaTeX fontName: 1–100 letters, digits, spaces, dots or hyphens, starting with a letter or digit. Sizes accept only whole numbers or decimals with one or two fractional digits, then apply role-specific inclusive bounds. Whitespace around values is trimmed; empty names, units, paths and TeX or CSS syntax are rejected. Last valid wins, but every invalid occurrence remains a diagnostic, just as for theme settings. Coordinates are zero-based: the fence map starts at its opener, so content line zero is source line map[0] + 1, also within lists and quotes.

            const report = (message: string): void => {
                diagnostics.push({ path: document!.path,
                    line: (token.map?.[0] ?? 0) + index + 1, column: 0, message });
            };
            if (key === 'font-code-ligatures') {
                if (value === 'on' || value === 'off') { codeLigatures = value === 'on'; }
                else { report(`Invalid ${key}: expected on or off`); }
            } else if (key.startsWith('font-size-')) {
                const role = key.slice('font-size-'.length) as keyof PublicationFontSizes;
                const bounds = publicationFontSizeBounds[role];
                const size = /^\d+(?:\.\d{1,2})?$/.test(value) ? Number(value) : NaN;
                if (Number.isFinite(size) && size >= bounds.minimum && size <= bounds.maximum) {
                    fontSizes[role] = size;
                } else {
                    const unit = role === 'diagram' ? 'CSS pixels' : 'points';
                    report(`Invalid ${key}: expected ${bounds.minimum}–${bounds.maximum} ${unit}`);
                }
            } else if (/^[A-Za-z0-9][A-Za-z0-9 .-]{0,99}$/.test(value)) {
                const role = key.slice(5) as keyof PublicationFonts;
                fonts[role] = value;
                if (role === 'note') { explicitNote = true; }
            } else {
                report(`Invalid ${key}: font must be a simple family name (1–100 ASCII characters)`);
            }
        });
    }
    if (!explicitNote) { fonts.note = fonts.body; }
    return { fonts, fontSizes, codeLigatures, diagnostics };
}
