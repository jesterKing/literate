Publication commands

The editor adapter owns prompts and a fresh source snapshot, not generation. Only trusted, local, desktop file workspaces on POSIX are supported, including LaTeX-only exports: the helper and diagram process lifecycle use POSIX signals. A global guard rejects overlapping publication commands. A supplied repository queue serializes source capture and helper cleanup with ordinary generation. No save-all, cached repository state, or generated source/HTML is used here.

Registration and configuration

registerPublicationCommands(context, serialize, bridge) registers literate.exportLatex and literate.exportPdf and attaches their disposables to the extension context. The optional PublicationQueue callback accepts one async operation and returns its result; without a callback, operations execute directly. The default bridge runs out/publication-helper.cjs as an external Node process.

The restricted, machine-scope string settings have empty defaults: literate.publication.nodePath names a compatible external Node executable, never Electron; literate.publication.browserPath is an optional absolute sandbox-capable Chromium executable; and literate.publication.fontManifest is optional root-relative JSON. Executable settings are read only from user/global values, never workspace or folder overrides. Dependencies such as Pandoc and latexmk/LuaLaTeX remain the helper's preflight responsibility. Fonts and licenses are optional disk inputs; editor overlays apply only to sources.

Workspace and geometry policy

The editor asks for top, outer, bottom, and inner margins. Inner is the binding edge: it is left on odd right-hand pages and right on even left-hand pages. Outer exchanges those physical edges. The extension sends explicit inner/outer CLI options, selecting a mirrored two-sided book rather than treating left and right as fixed page edges.

Recheck trust and workspace membership at asynchronous boundaries. A save dialog's initial directory is guidance, not containment enforcement. Each path is checked lexically and against disk ancestors, including dangling symlinks. Normal OS filesystem races cannot be eliminated by this adapter; the shared CLI additionally preflights and protects publication inputs at transaction time.

export function validateMargins(paper: string, value: string): string | undefined {
    const parts = value.split(',').map(part => part.trim());
    const values = parts.map(Number);
    if (parts.length !== 4 || parts.some(part => !/^\d+(?:\.\d+)?$/.test(part)) ||
        values.some(value => !Number.isFinite(value) || value < 5 || value > 50)) {
        return 'Enter four numbers in mm: top,outer,bottom,inner (each 5–50).';
    }
    const size = papers[paper];
    if (!size || size[0] - values[1] - values[3] < 80 || size[1] - values[0] - values[2] < 100) {
        return 'Margins must leave at least an 80 × 100 mm body.';
    }
    return undefined;
}

Canonical paths are also used for state keys. Symlink roots are rejected rather than allowing multiple aliases for the same project. Missing leaf paths are permitted for new buffers and output destinations, but existing ancestors must remain real directories.

function relativePath(root: string, target: string): string {
    const relative = path.relative(root, target).split(path.sep).join('/');
    const safe = safeRelativePath(relative);
    if (!safe || safe !== relative) { throw new Error(`Path must be inside the selected root: ${target}`); }
    return safe;
}
async function checkPath(root: string, relative: string): Promise<void> {
    let current = root;
    const parts = relative.split('/');
    for (let index = 0; index < parts.length; index++) {
        current = path.join(current, parts[index]);
        let stat;
        try { stat = await fs.lstat(current); }
        catch (error) { if ((error as NodeJS.ErrnoException).code === 'ENOENT') { return; } throw error; }
        if (stat.isSymbolicLink() || (index < parts.length - 1 ? !stat.isDirectory() : !stat.isFile())) {
            throw new Error(`Unsafe publication path (symlink or non-file): ${current}`);
        }
        if (await fs.realpath(current) !== current) { throw new Error(`Noncanonical path: ${current}`); }
    }
}
async function canonicalRoot(folder: vscode.WorkspaceFolder): Promise<string> {
    allowed(folder);
    const root = path.resolve(folder.uri.fsPath);
    if (await fs.realpath(root) !== root || !(await fs.lstat(root)).isDirectory()) {
        throw new Error('Publication root must be a real, canonical directory, not a symlink.');
    }
    return root;
}
async function canonicalProjectRoot(manifestRoot: string, relativeRoot: string): Promise<string> {
    let root = manifestRoot;
    for (const component of relativeRoot.split('/')) {
        root = path.join(root, component);
        const stat = await fs.lstat(root);
        if (stat.isSymbolicLink() || !stat.isDirectory() || await fs.realpath(root) !== root) {
            throw new Error(`Publication root must be a real, canonical directory: ${relativeRoot}`);
        }
    }
    return root;
}

Fresh source snapshot

All eligible open text is cloned synchronously before the first disk await. Empty buffers and new file-backed documents override disk just like nonempty buffers; untitled and foreign documents do not. Discovery is sorted and shares the engine's directory exclusions. No disk read of an overlaid source is needed.

<<publication extension snapshot>>=
export async function capturePublicationSnapshot(root: string, token: vscode.CancellationToken): Promise<SourceDocument[]> {
    cancelled(token);
    const overlays = new Map<string, string>();
    for (const document of vscode.workspace.textDocuments) {
        if (document.uri.scheme !== 'file' || document.uri.authority) { continue; }
        const relative = path.relative(root, document.uri.fsPath).split(path.sep).join('/');
        if (!relative.endsWith('.literate') || relative.startsWith('../') || path.isAbsolute(relative)) { continue; }
        if (relative.split('/').slice(0, -1).some(part => excluded.has(part))) { continue; }
        const safe = relativePath(root, document.uri.fsPath);
        overlays.set(safe, document.getText());
    }
    const documents = new Map<string, string>();
    let bytes = 0;
    const add = (name: string, text: string): void => {
        bytes += Buffer.byteLength(JSON.stringify({ path: name, text })) + 1;
        if (bytes > inputLimit) { throw new Error('Publication snapshot exceeds 32 MiB.'); }
        documents.set(name, text);
    };
    for (const [name, text] of overlays) {
        cancelled(token);
        await checkPath(root, name);
        add(name, text);
    }

The final serialized envelope is checked again, including arguments and JSON escaping. Source files are size-checked before reading; helper input is bounded independently. Binary assets, manifests, fonts and licenses stay on disk.

    const visit = async (directory: string): Promise<void> => {
        cancelled(token);
        const absolute = path.join(root, directory);
        if (await fs.realpath(absolute) !== absolute) { throw new Error(`Noncanonical source directory: ${absolute}`); }
        const entries = await fs.readdir(absolute, { withFileTypes: true });
        entries.sort((a, b) => a.name < b.name ? -1 : a.name > b.name ? 1 : 0);
        for (const entry of entries) {
            cancelled(token);
            if (entry.isSymbolicLink()) { continue; }
            const name = directory ? `${directory}/${entry.name}` : entry.name;
            if (entry.isDirectory() && !excluded.has(entry.name)) { await visit(name); }
            else if (entry.isFile() && name.endsWith('.literate') && !overlays.has(name)) {
                relativePath(root, path.join(root, name));
                await checkPath(root, name);
                if ((await fs.stat(path.join(root, name))).size > inputLimit) {
                    throw new Error(`Publication source exceeds 32 MiB: ${name}`);
                }
                add(name, await fs.readFile(path.join(root, name), 'utf8'));
            }
        }
    };
    await visit('');
    cancelled(token);
    return [...documents].sort(([a], [b]) => a < b ? -1 : a > b ? 1 : 0)

}

External process lifecycle

Never use a shell or the extension host executable. The helper enforces external Node >=22.12 and rejects Electron. The bridge bounds combined stdout/stderr and stdin. Its ten-minute execution deadline allows diagram (120s), TeX (180s) and preflight budgets, then requests graceful cancellation. Child close acknowledges termination; exit alone is insufficient because stdio may still be draining.

<<publication extension bridge>>=
export const runPublicationHelper: PublicationBridge = (node, helper, root, request, token, report) => {
    cancelled(token);
    const input = JSON.stringify(request);
    if (Buffer.byteLength(input) > inputLimit) { throw new Error('Publication request exceeds 32 MiB.'); }
    return new Promise((resolve, reject) => {
        const child = spawn(node, [helper], { cwd: root, shell: false, stdio: ['pipe', 'pipe', 'pipe'] });
        const stdout: Buffer[] = [], stderr: Buffer[] = [];
        let bytes = 0, failure: string | undefined, stopped = false;
        let grace: ReturnType<typeof setTimeout> | undefined;
        const stop = (reason?: string): void => {
            failure ??= reason;
            if (stopped) { return; }
            stopped = true;
            if (!child.kill('SIGTERM')) { report('Unable to deliver SIGTERM; waiting for helper exit.'); }
            grace = setTimeout(() => report('Helper has not acknowledged cancellation. Waiting for transaction cleanup; publication remains locked.'), 30000);
        };
        const timer = setTimeout(() => stop('Publication exceeded the 10 minute execution deadline.'), 600000);
        const subscription = token.onCancellationRequested(() => stop());
        const collect = (chunks: Buffer[], chunk: Buffer): void => {
            bytes += chunk.length;
            if (bytes > outputLimit) { stop('Publication helper output exceeds 8 MiB.'); }
            else { chunks.push(chunk); }
        };
        child.stdout.on('data', (chunk: Buffer) => collect(stdout, chunk));
        child.stderr.on('data', (chunk: Buffer) => collect(stderr, chunk));

There is deliberately no SIGKILL fallback: terminating a helper mid-rollback can abandon a transaction. If graceful cleanup stalls, report it and retain the lock until close rather than claiming cancellation completed or starting another writer. This is a bounded execution budget, not an unsafe hard cleanup deadline.

                    resolve(result);
                } catch (error) { reject(error); }
            }
        });

        if (!stopped) { child.stdin.end(input); }
        else { child.stdin.end(); }
    });

Cancellation requests SIGTERM but does not overwrite a committed outcome. After close, exit zero plus a valid written/current response is authoritative, even if cancellation arrived after commit. Transport errors, deadlines and output overflow remain failures regardless of exit code or response. Invalid protocol never becomes success merely because cancellation was requested.

    let response;
    try { response = JSON.parse(result.stdout); }
    catch { throw new Error(`Invalid JSON from publication helper:\n${result.stdout}`); }
    if (response?.schemaVersion !== 1 || response.command !== kind || response.ok !== true ||
        !Array.isArray(response.outputs) || !response.outputs.some((item: { path?: string; status?: string }) =>

Prompts and explicit dependencies

Remember only successful paper, margins and relative destination, separately for each canonical root and kind. Every prompt can cancel without spawning or writing. The active editor's workspace wins; otherwise offer all folders explicitly.

When Export PDF discovers a workspace manifest, that manifest denotes one ordered series operation rather than a publication choice. Every project must declare pdf before snapshots or helper work begin. The adapter then invokes the helper once with pdf <manifest-root> --json. The request carries project-relative snapshots keyed by publication ID; the helper reads paper, margins, and every manifest-relative output from the manifest. Snapshots remain isolated, while one helper lifecycle compiles the complete series and commits its PDFs together. Manifest-relative PDF paths may resolve outside a publication root. Export LaTeX and workspaces without a manifest retain the interactive single-publication protocol.

A validated outcome precedes cancellation state: a late cancellation cannot undo commit. Authority is separate and is checked before remembering, offering an open action and opening. If authority is revoked after commit, report the actual completed output without claiming failure or taking further success actions. Failure notifications are launched without awaiting user dismissal, so the command reaches its cleanup and releases the publication guard immediately. PDFs open via vscode.open, never as text documents.

Registration disposal cancels the active operation and removes event and command subscriptions immediately. The channel remains alive until the operation settles, so helper results and cleanup diagnostics cannot write to a disposed channel. Disposal does not release either guard early or force-kill the helper.
