Isolated vector diagrams

A diagram renderer is an optional asset producer, not the book's page-layout engine. Ordinary Mermaid fences become vector PDF and SVG companions. LaTeX fits the PDF using the same measured bounds as local illustrations; the SVG preserves editable vector content. No browser is needed for books without diagrams.

The author explicitly selects an installed Chromium executable. Puppeteer Core has no browser downloader. Its Node requirement belongs to this CLI feature, not to the extension's runtime. A separate process keeps its ESM dependencies and browser lifecycle outside normal generation and editor activation.

Bounded requests

Only the source text and a catalogue theme cross the worker boundary. Source locations remain in the controller, where failures can identify the chapter. The adapter contract returns bytes, never destinations or writes to the project.

Mermaid configuration is renderer-owned. Directives, frontmatter, authored HTML, CSS declarations and interaction commands are rejected, rather than relying on Mermaid to ignore them. The browser additionally validates the resulting SVG. The policy restricts capabilities, not diagram families: Mermaid's own detector selects any registered renderer. Quoted labels and comments do not act as commands; the keyword check masks them while preserving separators. Unquoted labels containing reserved command words should be quoted. HTML checks still examine the original source, including entity-encoded openers, regardless of quoting.

export function validateDiagram(source: string): void {
    if (!source.trim() || source.length > diagramLimits.source) {
        throw new Error('Mermaid source must contain 1–50000 characters');
    }
    if (/%%\s*\{/.test(source) || /^\s*---(?:\s|$)/.test(source)) {
        throw new Error('Mermaid directives and frontmatter are disabled');
    }
    if (/\b(?:style|classDef|linkStyle|click|links?)\s/i.test(commandText(source))
        || /<\s*\/?\s*[a-z][^>]*>/i.test(source)
        || /&(?:lt|#0*60|#x0*3c);/i.test(source)) {
        throw new Error('Mermaid authored HTML, CSS and interactions are disabled');
    }
}

Only double-quoted strings and line comments are masked. Escaped characters stay inside their string; a newline resets an unterminated quote so it cannot hide commands on subsequent lines. This small lexical pass does not replace Mermaid's parser or grant any additional browser capability.

<<Mermaid source policy>>=+
function commandText(source: string): string {
    let result = '', quoted = false, comment = false;
    for (let index = 0; index < source.length; index++) {
        const character = source[index];
        if (character === '\n' || character === '\r') {
            quoted = false; comment = false; result += character;
        } else if (comment) { result += ' '; }
        else if (quoted && character === '\\') {
            result += ' ';
            if (index + 1 < source.length && !/[\r\n]/.test(source[index + 1])) { index++; result += ' '; }
        } else if (character === '"') { quoted = !quoted; result += ' '; }
        else if (!quoted && character === '%' && source[index + 1] === '%') {
            comment = true; result += ' ';
        } else { result += quoted ? ' ' : character; }
    }
    return result;
}

Process lifetime

A POSIX process group lets the parent terminate the worker and Chromium together, including when browser close hangs. Normal completion also kills any descendants left by a failed close. Neither the shell nor a project-supplied configuration is used. The deadline and log cap remain enforceable even when browser JavaScript is stuck. Windows is rejected explicitly until equivalent process-tree ownership is available.

<<Mermaid worker execution>>=
export function executeDiagramWorker(directory: string, executable: string,
    worker = path.join(__dirname, 'publication-mermaid-worker.mjs'),
    timeoutMs = diagramLimits.timeMs): Promise<void> {
    return new Promise((resolve, reject) => {
        const child = spawn(process.execPath, ['--max-old-space-size=256', worker, directory, executable],
            { detached: true, stdio: ['ignore', 'pipe', 'pipe'], windowsHide: true });
        let failure = '', log = '', size = 0;
        const kill = (): void => {
            if (!child.pid) { return; }
            try { process.kill(-child.pid, 'SIGKILL'); }
            catch (error) { if ((error as NodeJS.ErrnoException).code !== 'ESRCH') { failure ||= String(error); } }
        };

}

The child reports bounded diagnostics only; binary results remain in the private directory. An exit status alone is insufficient: all expected artifacts are validated after the child exits. Any error prevents the publication transaction.

Regular-file and byte limits are checked before allocation and again afterwards. Worker filenames are numeric indexes chosen by the controller, never source paths. Chromium PDF timestamps are normalized in the worker, allowing unchanged exports with the same browser, Mermaid version and installed diagram fonts.

<<Mermaid artifact reads>>=
async function diagramArtifact(directory: string, index: number, format: 'pdf' | 'svg',
    checkCancelled?: () => void): Promise<Uint8Array> {
    const file = path.join(directory, `${index}.${format}`);
    const stat = await fs.lstat(file);
    checkCancelled?.();
    if (!stat.isFile() || stat.size < 1 || stat.size > diagramLimits[format]) {
        throw new Error(`Invalid or oversized Mermaid ${format} artifact`);
    }
    const bytes = await fs.readFile(file);
    checkCancelled?.();
    if (bytes.length > diagramLimits[format] || (format === 'pdf'
        ? bytes.subarray(0, 5).toString() !== '%PDF-' : !bytes.toString('utf8').startsWith('<svg'))) {
        throw new Error(`Invalid Mermaid ${format} artifact`);
    }
    return bytes;
}

Explicit browser selection

The executable must be an absolute path to a trusted, executable regular file. Symlinks at this explicit system-tool boundary are allowed, unlike project image paths. There is no PATH discovery, browser cache lookup, installation or sandbox fallback. Identical source strings render once for the selected theme.

The private directory owns both profile and artifacts, and is removed on every completion path. No writes reach the project until the caller receives a complete result. Cleanup errors are surfaced rather than reporting a successful export while leaving an undisclosed browser profile behind.

The caller supplies a persistent cancellation check, including cancellation latched before a lazy renderer import. Checks bracket asynchronous preparation and artifact reads. The final preparation check immediately precedes synchronous worker spawn; worker signal handlers own interruption while the child runs. Once a temporary directory exists, cancellation always passes through its cleanup scope.
