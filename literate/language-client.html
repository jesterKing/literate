Direct stdio language requests

This standalone Node client owns one executable and never invokes a shell or restarts a failed server. The adapter must establish workspace trust, choose the executable and arguments, and map completion/hover results. For example, TS7 uses tsc --lsp --stdio; ZLS likewise needs the initialize/initialized handshake. request and sync await that shared handshake; callers may initialize explicitly.

Messages and queued writes are bounded to 8 MiB (plus framing), headers to 8 KiB, and pending requests and initialization waiters to 128 each. Requests expire after 5 seconds, initialization after 15 seconds. Cancellation rejects with AbortError and sends $/cancelRequest once a request is on the wire. Protocol failures reject all pending work and terminate the process; stderr is drained in bounded chunks.

sync accepts the complete current document set, at most 1024 documents and 4 MiB of serialized document data. Unchanged text sends nothing. Changed language IDs close/reopen; a session-wide counter keeps each URI's versions increasing even across closes/reopens without retaining an unbounded history of closed URIs. Sync kind 0 is unsupported, kind 1 sends full text, and kind 2 replaces the old UTF-16 range. Projected documents require open/close support to establish their initial text: object-form synchronization must advertise openClose: true; legacy numeric kinds 1 and 2 imply open/close support without a separate flag. Configuration uses exact section keys first, then dotted own-property lookup; missing values are null. This client neither applies edits nor registers dynamic capabilities, watchers, server commands, or background restart loops. It advertises only user-invoked quick fixes and refactors, with no resource operations or edit annotation support. Diagnostics payloads remain untrusted: adapters validate them and compare versions against documentVersion. Closed documents and stopped sessions return undefined; state changes precede wire writes so even immediate diagnostics see the current version.

Disposal rejects outstanding work and allows 500 ms for shutdown and another 500 ms for exit before SIGKILL. Shutdown deliberately omits params for TS7. onDidStop runs once for failure or disposal after document versions are cleared; all subscriptions are then released. notify waits only when initialization is needed; request remains the generic entry point for pull diagnostics and other approved language requests. There is no VS Code or third-party runtime dependency.

The public boundary stays independent of editor types.

<<language client start>>=
    private async start(): Promise<void> {
        try {
            this.launch();
            const result = await this.rpc('initialize', {
                processId: process.pid, rootUri: this.options.rootUri,
                workspaceFolders: this.folders(), initializationOptions: this.options.initializationOptions,

Listeners are method-specific but not an execution surface: unknown server requests still fail closed. All subscriptions share 128 slots, return idempotent disposers, and may be registered before initialization. A late stop subscription fires immediately.

<<language client listeners>>=
    public onNotification(method: string, handler: (params: unknown) => void): () => void {
        if (this.stopped || this.closing) { return () => {}; }
        return this.listen({ method, handler });
    }

    public onDidStop(handler: () => void): () => void {
        if (this.stopped) { this.invoke({ handler }, undefined); return () => {}; }
        return this.listen({ handler });
    }

    private listen(listener: Listener): () => void {
        if (this.listeners.size >= 128) { throw new Error('LSP listener limit exceeded'); }
        this.listeners.add(listener);
        return () => { this.listeners.delete(listener); };
    }

    public documentVersion(uri: string): number | undefined { return this.documents.get(uri)?.version; }

Notifications are delivered synchronously only after readiness and outside shutdown. Callbacks added during delivery wait for the next event; removed callbacks stay removed. Failures log a constant message, never callback exceptions or notification payloads.

<<language client events>>=
    private emit(method: string, params: unknown): void {
        if (!this.initialized || this.closing || this.stopped) { return; }
        for (const listener of [...this.listeners]) {
            if (listener.method === method && this.listeners.has(listener)) { this.invoke(listener, params); }
        }
    }

    private invoke(listener: Listener, params: unknown): void {
        try { listener.handler(params); }
        catch {
            try { this.options.log?.('Language client listener failed'); } catch {  }
        }
    }

    public async notify(method: string, params: unknown): Promise<void> {
        if (!this.initialized) { await this.waitForInitialization(); }
        if (this.closing || this.stopped) { throw this.stopped || new Error('Language client disposed'); }
        this.send({ method, ...(params === undefined ? {} : { params }) });
    }

Drain every pipe and route process failures into one cleanup path.

<<language client launch>>=
    private launch(): void {
        const child = this.child = spawn(this.options.command, this.options.args || [], {
            cwd: this.options.cwd, shell: false, stdio: 'pipe'
        });
        this.exited = new Promise(resolve => {
            child.once('exit', (code, signal) => {
                this.fail(new Error(`Language server exited (${code ?? signal})`)); resolve();
            });
            child.once('error', error => { this.fail(error); resolve(); });
        });
        child.stdout.on('data', (chunk: Buffer) => {
            try { this.consume(chunk); } catch (error) { this.fail(failure(error)); }
        });
        child.stdout.on('end', () => this.fail(new Error('Language server stdout closed')));
        child.stdout.on('error', error => this.fail(error));
        child.stdin.on('error', error => this.fail(error));
        child.stderr.on('error', error => this.fail(error));
        child.stderr.on('data', (chunk: Buffer) => {
            try { this.options.log?.(chunk.subarray(0, 8192).toString('utf8')); } catch {  }
        });
    }

Read bytes, not JavaScript character counts; allocate only validated bodies.

<<language client consume>>=
    private consume(chunk: Buffer): void {
        while (chunk.length && !this.stopped) {
            if (!this.body) {
                const byte = chunk.subarray(0, 1);
                chunk = chunk.subarray(1);
                this.header = Buffer.concat([this.header, byte]);
                if (this.header.length > 8192) { throw new Error('LSP header limit exceeded'); }
                if (this.header.length < 4 || this.header.subarray(-4).toString() !== '\r\n\r\n') { continue; }
                const headers = this.header.toString('ascii').slice(0, -4).split('\r\n');
                const lengths = headers.filter(line => /^content-length:/i.test(line));
                if (lengths.length !== 1 || !/^content-length: *[0-9]+ *$/i.test(lengths[0])) {
                    throw new Error('Invalid LSP Content-Length');
                }
                const size = Number(lengths[0].split(':')[1]);
                if (!Number.isSafeInteger(size) || size < 1 || size > limit) { throw new Error('LSP message limit exceeded'); }
                this.body = Buffer.allocUnsafe(size); this.received = 0; this.header = Buffer.alloc(0);
            }
            const count = Math.min(chunk.length, this.body.length - this.received);
            chunk.copy(this.body, this.received, 0, count);
            this.received += count; chunk = chunk.subarray(count);
            if (this.received === this.body.length) {
                const message: unknown = JSON.parse(new TextDecoder('utf-8', { fatal: true }).decode(this.body));
                this.body = undefined; this.received = 0; this.dispatch(message);
            }
        }
    }

Separate server requests from responses and reject malformed envelopes.

<<language client dispatch>>=
    private dispatch(message: unknown): void {
        if (!object(message) || message.jsonrpc !== '2.0') { throw new Error('Invalid JSON-RPC message'); }
        if (typeof message.method === 'string') {
            if (message.id !== undefined) {
                if (typeof message.id !== 'number' && typeof message.id !== 'string') { throw new Error('Invalid request id'); }
                this.answer(message.method, message.params, message.id);
            } else { this.emit(message.method, message.params); }
            return;
        }
        if (typeof message.id !== 'number' || (('result' in message) === ('error' in message))) {
            throw new Error('Invalid JSON-RPC response');
        }
        const pending = this.pending.get(message.id);
        if ('error' in message) {
            if (!object(message.error) || typeof message.error.message !== 'string' || typeof message.error.code !== 'number') {
                throw new Error('Invalid JSON-RPC error');
            }
            pending?.finish(Object.assign(new Error(message.error.message), { code: message.error.code, data: message.error.data }));
        } else { pending?.finish(undefined, message.result); }
    }

Resolve only configured own properties; never inherited settings.

<<language client section>>=
    private section(section: unknown): unknown {
        const config = this.options.configuration || {};
        if (section === undefined || section === '') { return config; }
        if (typeof section !== 'string') { return null; }
        if (Object.prototype.hasOwnProperty.call(config, section)) { return config[section] ?? null; }
        let value: unknown = config;
        for (const key of section.split('.')) {
            if (!object(value) || !Object.prototype.hasOwnProperty.call(value, key)) { return null; }
            value = value[key];
        }
        return value ?? null;
    }

Answer the small read-only server request surface explicitly.

<<language client answer>>=
    private answer(method: string, params: unknown, id: string | number): void {
        let result: unknown;
        if (method === 'workspace/configuration' && object(params) && Array.isArray(params.items)) {
            result = params.items.map(item => object(item) ? this.section(item.section) : null);
        } else if (method === 'workspace/workspaceFolders') { result = this.folders(); }
        else if (method === 'workspace/diagnostic/refresh' && this.initialized && !this.closing) {
            this.send({ id, result: null }); this.emit(method, params); return;
        }
        else if (method === 'workspace/applyEdit') { result = { applied: false, failureReason: 'Read-only language client' }; }
        else {
            this.send({ id, error: { code: -32601, message: `Unsupported method: ${method}` } }); return;
        }
        this.send({ id, result });
    }

Bound queued writes as well as individual payloads.

<<language client send>>=
    private send(message: ObjectValue): void {
        if (this.stopped || !this.child) { throw this.stopped || new Error('Language server not started'); }
        const body = Buffer.from(JSON.stringify({ jsonrpc: '2.0', ...message }), 'utf8');
        if (body.length > limit) { throw new Error('LSP outgoing message limit exceeded'); }
        const header = Buffer.from(`Content-Length: ${body.length}\r\n\r\n`, 'ascii');
        if (this.child.stdin.writableLength + header.length + body.length > limit + 8192) {
            const error = new Error('LSP output queue limit exceeded'); this.fail(error); throw error;
        }
        this.child.stdin.write(Buffer.concat([header, body]));
    }

<<language client request>>=
    public async request(method: string, params: unknown, signal?: AbortSignal): Promise<unknown> {
        if (signal?.aborted) { throw this.cancelled(); }
        await this.waitForInitialization(signal);
        if (this.closing) { throw new Error('Language client disposed'); }
        return this.rpc(method, params, signal);

Cancellation while waiting must not cancel shared initialization.

<<language client waitForInitialization>>=
    private waitForInitialization(signal?: AbortSignal): Promise<void> {
        if (this.waiting >= 128) { return Promise.reject(new Error('LSP initialization wait limit exceeded')); }
        this.waiting++;
        const ready = this.initialize().finally(() => { this.waiting--; });
        if (!signal) { return ready; }
        return new Promise((resolve, reject) => {
            const abort = () => { signal.removeEventListener('abort', abort); reject(this.cancelled()); };
            signal.addEventListener('abort', abort, { once: true });
            ready.then(() => { signal.removeEventListener('abort', abort); resolve(); }, error => {
                signal.removeEventListener('abort', abort); reject(error);
            });
            if (signal.aborted) { abort(); }
        });
    }

Every pending slot owns its timeout and abort listener until settlement.

<<language client rpc>>=
    private rpc(method: string, params: unknown, signal?: AbortSignal, timeout = 5000): Promise<unknown> {
        if (this.stopped) { return Promise.reject(this.stopped); }
        if (signal?.aborted) { return Promise.reject(this.cancelled()); }
        if (this.pending.size >= 128) { return Promise.reject(new Error('LSP pending request limit exceeded')); }
        return new Promise((resolve, reject) => {
            const id = ++this.sequence;
            const finish = (error?: Error, value?: unknown) => {
                if (!this.pending.delete(id)) { return; }
                clearTimeout(timer); signal?.removeEventListener('abort', abort);
                if (error) { reject(error); } else { resolve(value); }
            };
            const cancel = (error: Error) => {
                finish(error);
                try { this.send({ method: '$/cancelRequest', params: { id } }); } catch (error) { this.fail(failure(error)); }
            };
            const abort = () => cancel(this.cancelled());
            const timer = setTimeout(() => cancel(new Error(`LSP request timed out: ${method}`)), timeout);
            this.pending.set(id, { finish });
            signal?.addEventListener('abort', abort, { once: true });
            try { this.send({ id, method, ...(params === undefined ? {} : { params }) }); }
            catch (error) { finish(failure(error)); }
        });
    }

Validate the document set before notifying the server.

Complete-set synchronization is presented in Owning a language-server session.

Incremental servers receive a single full-range replacement.

<<language client updateDocument>>=
    private updateDocument(doc: LanguageDocument, kind: unknown, openClose: boolean): void {
        const old = this.documents.get(doc.uri);
        if (old?.text === doc.text) { return; }
        if (this.documentSequence >= 2147483647) {
            const error = new Error('LSP document version limit exceeded'); this.fail(error); throw error;
        }
        const version = ++this.documentSequence;
        this.documents.set(doc.uri, { ...doc, version });
        if (!old && openClose) {
            this.send({ method: 'textDocument/didOpen', params: { textDocument: { ...doc, version } } });
        } else {
            const lines = (old?.text || '').split(/\r\n|\r|\n/);
            const range = { start: { line: 0, character: 0 }, end: { line: lines.length - 1, character: lines[lines.length - 1].length } };
            this.send({ method: 'textDocument/didChange', params: {
                textDocument: { uri: doc.uri, version }, contentChanges: [{ ...(kind === 2 ? { range } : {}), text: doc.text }]
            } });
        }
    }

A terminal failure releases buffers, document snapshots, and all promises.

<<language client fail>>=
    private fail(error: Error): void {
        if (this.stopped) { return; }
        this.stopped = error;
        for (const pending of this.pending.values()) { pending.finish(error); }
        this.documents.clear(); this.header = Buffer.alloc(0); this.body = undefined;
        for (const listener of [...this.listeners]) {
            if (listener.method === undefined && this.listeners.has(listener)) { this.invoke(listener, undefined); }
        }
        this.listeners.clear();
        this.child?.stdin.destroy(); this.child?.stdout.destroy(); this.child?.stderr.destroy();
        if (this.child && this.child.exitCode === null && this.child.signalCode === null) { this.child.kill('SIGKILL'); }
    }

Give a cooperative server time to exit, then force termination.

<<language client stop>>=
    private async stop(): Promise<void> {
        if (this.initialized && !this.stopped) {
            for (const pending of this.pending.values()) { pending.finish(new Error('Language client disposed')); }
            try {
                await this.rpc('shutdown', undefined, undefined, 500);
                this.send({ method: 'exit' });
                await new Promise<void>(resolve => {
                    const timer = setTimeout(resolve, 500);
                    this.exited?.then(() => { clearTimeout(timer); resolve(); });
                });
            } catch {  }
        }
        this.fail(new Error('Language client disposed'));
    }
