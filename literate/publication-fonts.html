Explicit portable font companions

This chapter owns src/publication-fonts.ts and its headless tests. A manifest is an explicit publishing allowlist, never a request to scan Fonts or query installed families. Version 1 requires regular, bold, italic and boldItalic mappings plus a nonempty licenses array for every family. String mappings select real files with no synthesis. Italic faces alone may explicitly request bounded synthetic slant.

Files and face choices

The filesystem adapter rejects symbolic links in every component and requires regular files. Validation covers even unselected entries, but only selected families' bytes are copied. All declared inputs remain protected from outputs. A synthesized face still names an explicit file: there is no implicit fallback.

<<portable font contract>>= 
import { createHash } from 'crypto';
import { posix } from 'path';
import { safeRelativePath } from './engine';

export const fontFaces = ['regular', 'bold', 'italic', 'boldItalic'] as const;
export type FontFace = string | { file: string; slant: number };
export type PortableFont = Record<typeof fontFaces[number], FontFace>;
export interface FontPlan {
    fonts: Record<string, PortableFont>;
    inputs: string[];
    files: { path: string; content: Uint8Array }[];
}
export interface FontInputIO {
    requireFile(path: string): Promise<void>;
    read(path: string): Promise<Uint8Array>;
}
export const fontFile = (face: FontFace): string => typeof face === 'string' ? face : face.file;
const digest = (text: string): string => createHash('sha256').update(text).digest('hex');

Strict schema helpers

JSON containers must be objects, never arrays or null. We retain the contextual field location in errors rather than letting a later property access fail.

<<portable font object validation>>= 
function object(value: unknown, where: string): Record<string, unknown> {
    if (!value || typeof value !== 'object' || Array.isArray(value)) {
        throw new Error(`${where}: expected a JSON object`);
    }
    return value as Record<string, unknown>;
}

Unknown fields are errors so misspelled face, synthesis and license declarations cannot silently disappear. Required fields are checked by their value validators.

<<portable font field validation>>= 
function keys(value: Record<string, unknown>, allowed: readonly string[], where: string): void {
    for (const key of Object.keys(value)) {
        if (!allowed.includes(key)) { throw new Error(`${where}: unknown field ${key}`); }
    }
}

Paths use the shared portable root-relative policy. Font containers are limited to .ttf and .otf; validation does not parse font binaries or determine whether a license legally permits redistribution. License contents remain opaque bytes.

<<portable font path validation>>= 
function inputPath(value: unknown, where: string, font = false): string {
    const result = typeof value === 'string' ? safeRelativePath(value) : undefined;
    if (!result) { throw new Error(`${where}: expected a safe root-relative file path`); }
    if (font && !/\.(ttf|otf)$/i.test(result)) {
        throw new Error(`${where}: expected a .ttf or .otf font file`);
    }
    return result;
}

Only italic and boldItalic accept {file, slant}. The slant must be a finite number from 0.01 through 0.3; 0.2 matches the approved D2 code-comment style. There is no synthetic weight, no arbitrary fontspec feature string and no coercion from strings. The renderer reuses this validator with a stricter companion path grammar, so programmatic callers cannot bypass synthesis checks.

<<portable font face validation>>= 
export function checkFontFace(value: unknown, face: typeof fontFaces[number], where: string,
    filePath: (value: unknown, where: string) => string): FontFace {
    if (!value || typeof value !== 'object') { return filePath(value, where); }
    if (face !== 'italic' && face !== 'boldItalic') {
        throw new Error(`${where}: synthesis is only supported for italic and boldItalic`);
    }
    const choice = object(value, where);
    keys(choice, ['file', 'slant'], where);
    if (typeof choice.slant !== 'number' || !Number.isFinite(choice.slant) ||
        choice.slant < 0.01 || choice.slant > 0.3) {
        throw new Error(`${where}.slant: expected a finite number from 0.01 through 0.3`);
    }
    return { file: filePath(choice.file, `${where}.file`), slant: choice.slant };
}

Plan before publishing

The traversal separates decoding, validation and copying. Its order is unchanged: all entries are validated and checked for existence before any selected bytes are copied. The caller preflights collisions and publishes the in-memory plan through its existing transaction, not through separate writes.

<<portable font plan>>= 
export async function planFonts(manifestPath: string, output: string,
    selected: readonly string[], io: FontInputIO): Promise<FontPlan> {
    const context = `Font manifest ${manifestPath}`;

    const plan: FontPlan = { fonts: Object.create(null), inputs: [...inputs], files: [] };

    return plan;
}

The manifest is itself a protected input. Malformed JSON gets the manifest path in its error; unsupported versions fail before interpreting any family entries.

<<decode portable font manifest>>= 
await io.requireFile(manifestPath);
let parsed: unknown;
try { parsed = JSON.parse(Buffer.from(await io.read(manifestPath)).toString('utf8')); }
catch (error) { throw new Error(`${context}: cannot read JSON: ${String(error)}`); }
const manifest = object(parsed, context);
keys(manifest, ['version', 'families'], context);
if (manifest.version !== 1) { throw new Error(`${context}: version must be 1`); }
const families = object(manifest.families, `${context}.families`);

Family names use the same simple grammar as root settings. Sorted traversal keeps output order independent of JSON property order. Every face must name a file, including the file underlying an explicitly synthesized italic face.

<<validate portable font families>>= 
for (const family of Object.keys(families).sort()) {
    const where = `${context}.families[${JSON.stringify(family)}]`;
    if (!/^[A-Za-z0-9][A-Za-z0-9 .-]{0,99}$/.test(family)) {
        throw new Error(`${where}: expected a simple family name`);
    }
    const entry = object(families[family], where);
    keys(entry, [...fontFaces, 'licenses'], where);
    const faces = {} as PortableFont;
    for (const face of fontFaces) {
        faces[face] = checkFontFace(entry[face], face, `${where}.${face}`,
            (value, location) => inputPath(value, location, true));
        inputs.add(fontFile(faces[face]));
    }
    <<validate portable font licenses>>
    entries.set(family, { faces, licenses });
}

A nonempty license list is mandatory for each family. Unselected licenses are validated and protected too, even though they will not be exported.

<<validate portable font licenses>>= 
if (!Array.isArray(entry.licenses) || !entry.licenses.length) {
    throw new Error(`${where}.licenses: expected a nonempty array of license file paths`);
}
const licenses = entry.licenses.map((value, index) => inputPath(value, `${where}.licenses[${index}]`));
licenses.forEach(value => inputs.add(value));

Completeness is checked before copying anything. There is no installed-family fallback in manifest mode. Filesystem diagnostics identify the failing input regardless of whether that input belongs to a selected family.

<<require portable font inputs>>= 
for (const family of selected) {
    if (!entries.has(family)) {
        throw new Error(`${context}: selected family ${JSON.stringify(family)} is missing; add all four faces and licenses`);
    }
}
for (const input of inputs) {
    try { await io.requireFile(input); }
    catch (error) { throw new Error(`${context}: input ${JSON.stringify(input)}: ${String(error)}`); }
}

The output basename is hashed into a private sibling directory. Family and face identities are hashed as well: no source path, family text or output basename is interpolated into TeX. Names remain stable across file and synthesis-setting updates. Move the book and this directory together; compile from their parent.

<<copy selected portable fonts>>= 
for (const family of [...new Set(selected)].sort()) {
    const entry = entries.get(family)!;
    const faces = {} as PortableFont;
    const copy = async (source: string, identity: string, extension: string): Promise<string> => {
        const name = `${directory}/${digest(family + ':' + identity)}${extension}`;
        plan.files.push({ path: posix.join(posix.dirname(output), name), content: await io.read(source) });
        return name;
    };
    <<copy portable font faces>>
    for (const [index, license] of entry.licenses.entries()) {
        await copy(license, `license-${index}`, '.license.txt');
    }
    plan.fonts[family] = faces;
}

Copying preserves bytes, not just decoded text. A synthesized face retains only its validated numeric slant alongside the new safe companion path; it never carries a raw source path into rendering.

<<copy portable font faces>>= 
for (const face of fontFaces) {
    const choice = entry.faces[face];
    const source = fontFile(choice);
    const file = await copy(source, face, posix.extname(source).toLowerCase());
    faces[face] = typeof choice === 'string' ? file : { file, slant: choice.slant };
}

function fixture(t: { after(callback: () => void): void }): string {

The CLI helper records conversion calls. Tree snapshots retain file contents and mtimes while ignoring directory mtimes, which rollback need not restore.

<<portable font test helpers>>= 
async function command(root: string, factory = createTransactionIO, output = 'books/book.tex',
    manifestPath = 'config/fonts.json') {
    let stdout = '', calls = 0;
    const code = await run(['latex', root, '--output', output, '--font-manifest', manifestPath, '--json'], {
        stdout: text => { stdout += text; }, stderr: text => assert.fail(text)
    }, factory, async () => { calls++; return 'Book body'; });
    const response = JSON.parse(stdout) as { errors: string[]; outputs: { path: string; status: string }[] };
    return { code, response, calls };
}
function tree(root: string): unknown {
    return fs.readdirSync(root).sort().map(name => {
        const file = path.join(root, name), stat = fs.lstatSync(file);
        return [name, stat.isDirectory() ? null : stat.mtimeMs, stat.isSymbolicLink() ? fs.readlinkSync(file)
            : stat.isDirectory() ? tree(file) : fs.readFileSync(file).toString('hex')];
    });
}
