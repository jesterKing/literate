Executable configuration never uses a merged getter. The resource-scoped automaticCompletion boolean is separate and defaults to true. Invalid entries receive a fixed diagnostic; aliases normalize fence labels, not configuration keys. Omitted arguments mean an empty array. Executables run without a shell through the existing client. Output never includes configuration values, source, protocol errors or stderr.

A single-buffer parse scopes Escape immediately, without disk capture or graph expansion. Token maps and the shared header parser exclude prose and fence lines; reference spans and unfinished markers are excluded too. This proves only a local body, never a generated mapping: requests still require full snapshot projection.

function localBody(document: vscode.TextDocument, cursor: vscode.Position): boolean {
    try {
        const text = document.getText(), lines = text.split(/\r\n|\r|\n/);
        const parsed = parseProject([{ path: 'input.literate', text }]);
        const token = parsed.documents[0]?.tokens.find(value => value.type === 'fence' && value.map
            && cursor.line > value.map[0] && cursor.line < value.map[1]);
        if (!token?.map) { return false; }
        const header = parseFragmentHeader(token.info);
        if (!header || (header.language && !servers()[language(header.language)])) { return false; }
        const bodyLines = token.content.split('\n'), index = cursor.line - token.map[0] - 1;
        if (index >= bodyLines.length - (token.content.endsWith('\n') ? 1 : 0)) { return false; }
        const body = bodyLines[index], column = cursor.character - (lines[cursor.line].length - body.length);
        if (column <= 0 || column > body.length) { return false; }
        const before = body.slice(0, column - 1) + body.slice(column);
        if (before.trim().startsWith(token.markup)) { return false; }
        if (scanFragmentTags(body).some(tag => column >= tag.start && column <= tag.end + (tag.modifier?.length ?? 0))) {

Treat replies as untrusted data

Positions use UTF-16 indexes and reject out-of-line coordinates rather than clamping them. Every edit must stay in the original occurrence, on the cursor's line, and contain the cursor. Unsupported completion defaults reject the list; commands and auxiliary edits reject the item. Snippets use the standard VS Code SnippetString interpreter, including its normal variables; no shell is involved.

function offset(text: string, value: unknown): number | undefined {
    if (!object(value) || !Number.isSafeInteger(value.line) || !Number.isSafeInteger(value.character)
        || (value.line as number) < 0 || (value.character as number) < 0) { return undefined; }
    const lines = text.split(/\r\n|\r|\n/);
    const line = value.line as number, character = value.character as number;
    if (line >= lines.length || character > lines[line].length) { return undefined; }
    let start = 0, index = 0;
    for (const match of text.matchAll(/\r\n|\r|\n/g)) {
        if (index++ === line) { break; }
        start = match.index! + match[0].length;
    }
    return start + character;
}

One operation with bounded foreground waiting

At most 32 foreground requests wait for the serialization gate. Cancellation and freshness are checked before acquisition; foreground work precedes background work. The operation owns initialization, full synchronization and its reply as one unit. Every asynchronous boundary checks document version, the global revision epoch, folder membership, trust, configuration and cancellation. Disk events invalidate literate inputs and captured template paths. Paths changing during capture are bounded and checked against the completed template input set. Non-input changes, including publication outputs and transaction files, do not cancel cold startup. New source files always invalidate; missing templates cannot yield suggestions.
