Links are resolved from the viewing document, not the definition's file. Preview asks the existing capability adapter for every included family, including families that only appear inside unopened expansions. No raw editor URLs are constructed. The client does not trust those strings merely because they occur in JSON.

Expanded links prefer an existing baseline anchor for the same target. New links accept only matching fragments, ./ HTML paths, or native Literate capabilities: vscode/vscode-insiders, authority jesterking.literate, and exactly /navigate/<48 lowercase hex>/<48 lowercase hex>, with an optional host query but no fragment. Query transport does not change the capability path. HTTPS is borrowed only from a same-target baseline anchor, never from payload metadata alone; otherwise the reference remains text with its disclosure intact. The host still checks native token membership and expiry. No new transport API is assumed: arbitrary HTTPS asExternalUri shapes cannot be authenticated here.

A requested panel is preflighted before candidate DOM allocation. Duplicate part IDs are rejected rather than repeated or silently deduplicated. At most 200 parts and 4096 segments are visited, with conservative escaped-byte accounting including controls and later status text. Private panel ownership tracks costs; DOM data attributes are diagnostic only. Collapse, detach and payload removal release all owned descendants. Identity/link changes invalidate panels and focused teardown returns to a surviving root disclosure or baseline anchor.

export function explorationPayload(model: PublicationModel, path: string, format: ScreenFormat,
    destination?: PreviewDestination): string {
    const neutral = neutralModel(model);
    if (neutral.unavailable) { return serializeExploration(neutral); }
    const value = { ...neutral, families: Object.create(null) as ExplorationPayload['families'] };
    const index = screenIndex(model);
    let budget = Buffer.byteLength(serializeExploration(neutral), 'utf8');

        const base = index.parts.get(family.parts[0]);
        const href = base && screenHref(path, base.definition.path, target, format, destination);

Link authority precedes rendering

Payload links must match the target and an accepted local or native capability shape. Native capabilities retain host-added queries, but never fragments or a changed authority or path. HTTPS requires a baseline anchor supplied by the host, never JSON authority alone. Invalid destinations stay text.

<<exploration browser safe href>>=
function safeHref(href, target, baseline = false) {
    if (typeof href !== 'string' || href.length > 4096 || /[\s\u0000-\u001f\u007f\\]/.test(href)) { return undefined; }
    if (identifier(target) && href === '#' + target) { return href; }
    if (identifier(target) && href.endsWith('#' + target)) {
        const path = href.slice(0, -target.length - 1);
        if (path.startsWith('./') && path.endsWith('.html') && path.slice(2).split('/').every(
            part => /^(?:[A-Za-z0-9_~.!'()*-]|%[0-9a-fA-F]{2})+$/.test(part))) { return href; }
    }
    if (/^vscode(?:-insiders)?:\/\/jesterking\.literate\/navigate\/[a-f0-9]{48}\/[a-f0-9]{48}(?:\?[^#]*)?$/.test(href)) { return href; }
    if (baseline && /^https:\/\//.test(href)) {
        try {
            const url = new view.URL(href);
            if (url.protocol === 'https:' && url.hostname && !url.username && !url.password) { return href; }
        } catch (_) {  }
    }
    return undefined;
}

A baseline decision wins even when its value is undefined: rejected or conflicting host anchors cannot be bypassed by falling back to payload metadata.

Preflight before candidate DOM

Serialized cost includes UTF-8 bytes and conservative escaping overhead. An oversized string fails before encoding, and the estimate needs neither candidate DOM nor an expanded serialization.

<<exploration browser escaped cost>>=
function escapedCost(text) {
    if (typeof text !== 'string' || text.length > limits.bytes) { return Infinity; }
    let cost = encoder.encode(text).length;
    for (const character of text) {
        if (character === '&') { cost += 4; }
        else if (character === '<' || character === '>') { cost += 3; }
        else if (character === '"' || character === "'") { cost += 5; }
    }
    return cost;
}

function readModel(source) {
    try {
        if (source.length > limits.payload || encoder.encode(source).length > limits.payload) { throw new Error('payload limit'); }
        const model = JSON.parse(source);
        if (!record(model) || model.version !== 1 || !record(model.parts) || !record(model.families)) { throw new Error('invalid model'); }

}

function baselineLinks(root) {
    const links = new Map();

        if (inPanel(anchor)) { continue; }
        const target = anchor.getAttribute('data-literate-target');
