Renaming fragments

Rename uses the shared symbol planner, so only explicit fragment names change. Validation rejects ambiguous definitions, collisions and changes to root status without touching prose, filenames or generated output.

Preparing a rename refreshes the read-only repository from open buffers. The shared lookup supplies the inner name range, excluding the tag delimiters. A no-op plan also verifies that the selected symbol has one base definition.

<<prepare fragment rename>>= 
public async prepareRename(
    document : vscode.TextDocument,
    position : vscode.Position,
    token : vscode.CancellationToken
)
{
    if(token.isCancellationRequested) { return null; }
    const workspaceFolder = determineWorkspaceFolder(document);
    if(!workspaceFolder) { return null; }
    await this.repository.processLiterateFiles(document);
    if(token.isCancellationRequested) { return null; }
    const location = this.repository.getFragmentTagLocation(
        document, document.lineAt(position.line), position
    );
    if(!location.valid || !location.fragment) { return null; }
    planFragmentRename(
        this.repository.getSourceDocuments(workspaceFolder), location.name, location.name
    );
    if(token.isCancellationRequested) { return null; }
    return { range: location.rangeExclusive, placeholder: location.name };
}

The actual request refreshes again: the user may have edited a buffer since preparation. Cancellation discards the whole result, never a partial edit set. Planner errors propagate to the editor as actionable rename failures.

Planner paths are canonical workspace-relative source paths. Convert their UTF-16 name ranges to editor edits without reading disk or applying changes.

<<adapt fragment rename plan>>= 
const workspaceEdit = new vscode.WorkspaceEdit();
for(const edit of plan)
{
    if(token.isCancellationRequested) { return null; }
    workspaceEdit.replace(
        vscode.Uri.joinPath(workspaceFolder.uri, edit.path),
        new vscode.Range(edit.line, edit.startColumn, edit.line, edit.endColumn),
        edit.newText
    );
}
return token.isCancellationRequested ? null : workspaceEdit;
