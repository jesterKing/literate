Shared semantic screen rendering

Both screen adapters use accepted publication contributions and the whole-block syntax emitter. Only semantic reference ranges become links; HTML is never rescanned for tags. This module has no filesystem or VS Code dependency.

The adapter chooses destinations without changing logical identity. Fixed-width IDs are shared with LaTeX; URL components, labels and attributes are escaped separately. Preview supplies a synchronous lookup of asynchronously resolved URLs.

Relative links work from nested chapters and percent-encode filenames (including spaces, percent signs, hashes and colons). A leading dot prevents a filename from being interpreted as a URI scheme. Same-document destinations are native anchors. Cross-document preview links use only the extension's capability adapter. Pending or failed resolutions stay text: native line-link fallback can create divergent fragment-qualified documents in the host. Logical identity remains in data-literate-target, independent of the opaque session URL.

Screen destination adaptation is presented in Publication on screen.

Syntax is intersected with semantic spans, never used to discover them. Hiding comment-only syntax retains the existing screen policy, but references inside comments remain navigable. Unknown languages stay plain; the publication adapter checks the pinned emitter's shape and exact text reconstruction.

export function renderScreenContribution(part: PublicationContribution, model: PublicationModel,

Native anchors are keyboard-focusable and carry descriptive accessible names. Contribution anchors retain source mapping for the current preview. Fragment references and declaration labels provide direct semantic navigation; contribution blocks add no previous, base, or next chrome.

Immutable publication snapshots are indexed once and weakly cached, so references and adapter lookups do not rescan the project. A fresh parse creates a fresh snapshot; the weak cache does not retain closed projects. Nested document maps avoid path/key delimiter collisions.

const screenIndexes = new WeakMap<PublicationModel, ReturnType<typeof buildScreenIndex>>();
const annotationIndexes = new WeakMap<PublicationAnnotations, WeakMap<PublicationModel, ReturnType<typeof buildScreenIndex>>>();
export function screenIndex(model: PublicationModel, annotations?: PublicationAnnotations) {
    let cache = screenIndexes;
    if (annotations) {
        if (!annotationIndexes.has(annotations)) { annotationIndexes.set(annotations, new WeakMap()); }
        cache = annotationIndexes.get(annotations)!;
    }
    let index = cache.get(model);
    if (!index) { index = buildScreenIndex(model, annotations); cache.set(model, index); }
    return index;
}

The preview host applies aliases before highlight.js. Our semantic overlay replaces its highlighter, so apply the same compatibility mapping explicitly, without changing the authored language or LaTeX policy. Unknown languages stay plain.

<<screen preview language aliases>>=
export function previewLanguage(language: string): string {
    switch (language.toLowerCase()) {
        case 'shell': return 'sh';
        case 'py3': return 'python';
        case 'tsx': case 'typescriptreact': return 'jsx';
        case 'json5': case 'jsonc': return 'json';
        case 'c#': case 'csharp': return 'cs';
        default: return language;
    }
}

Literal ranges and references arrive in source order. A monotonic syntax cursor visits each syntax leaf once (plus split boundaries), rather than rescanning every leaf per reference. A leaf straddling a reference remains available for its suffix.

<<screen syntax merge>>=
function screenSyntax(display: ReturnType<typeof highlightContribution>) {
    let index = 0;
    return (start: number, end: number): string => {
        const output: string[] = [];
        while (index < display.spans.length) {
            const span = display.spans[index];
            if (span.end <= start) { index++; continue; }
            if (span.start >= end) { break; }
            const left = Math.max(start, span.start), right = Math.min(end, span.end);
            const scope = span.scope.split('.')[0];
            if (left < right && scope !== 'comment') {
                const text = escapeHtml(display.text.slice(left, right));
                output.push(scope ? `<span class="hljs-${escapeHtml(scope)}">${text}</span>` : text);
            }
            if (span.end > end) { break; }
            index++;
        }
        return output.join('');
    };
}

Annotation prose

Annotation bodies use the collector's parser, preserving reference aliases, autolinks and occurrence offsets. A closed token vocabulary keeps raw HTML, images, headings and code fences from introducing active elements or attributes. The title is plain text; NOTE has its own numbered aside, never a term identity.

export function renderScreenAnnotation(annotation: PublicationTerm | PublicationNote,
    context: ScreenAnnotationContext): string {
    const term = 'title' in annotation;
    const tag = term ? 'section' : 'aside';
    const title = term ? annotation.title : `Note ${annotation.number}`;
    const source = context.format === 'preview' ? ` code-line" data-line="${annotation.at.line}` : '';
    const tokens = sanitizeAnnotationTokens(parseAnnotationBody(annotation.body));
    const literateUseTargets = screenTermUseAnchors(tokens, context.annotations, annotation.target);
    return `<${tag} class="literate-annotation literate-${term ? 'term' : 'note'}${source}" id="${annotation.target}">`
        + `<div class="literate-annotation-title">${escapeHtml(title)}</div>`
        + annotationMarkdown.renderer.render(tokens, annotationMarkdown.options,
                    { literateScreen: context, literateUseTargets }) + `</${tag}>\n`;
}

Sanitization preserves every token slot, so the collector's token and child indexes still identify the rendered links. Rejected leaf content becomes escaped text; rejected containers lose their tags, not their accepted inline children. Only parser-owned link and ordered-list attributes survive.

<<screen annotation body sanitization>>=
const screenBodyTokens = new Set([
    'paragraph_open', 'paragraph_close', 'inline', 'text', 'softbreak', 'hardbreak',
    'bullet_list_open', 'bullet_list_close', 'ordered_list_open', 'ordered_list_close',
    'list_item_open', 'list_item_close', 'em_open', 'em_close', 'strong_open',
    'strong_close', 'code_inline', 'link_open', 'link_close'
]);
function sanitizeAnnotationTokens(tokens: Token[]): Token[] {
    for (const token of tokens) {
        if (!screenBodyTokens.has(token.type)) {
            token.type = 'text'; token.tag = ''; token.nesting = 0;
            token.children = null; token.hidden = false;
        } else if (token.children) { sanitizeAnnotationTokens(token.children); }
        token.attrs = token.attrs?.filter(([name]) =>
            (token.type === 'link_open' && (name === 'href' || name === 'title'))
            || (token.type === 'ordered_list_open' && name === 'start')) || null;
    }
    return tokens;
}

Semantic prose fragment tokens use the same family destinations as code references; the [rail] suffix was consumed before rendering and does not affect screens. Other links retain the host renderer's behavior and Markdown URL validation.

export function installScreenFragmentLinks(md: MarkdownIt): void {
    md.renderer.rules.literate_fragment_use = (tokens, index, _options, env) => {
        const token = tokens[index];
        const context = env?.literateScreen as ScreenAnnotationContext | undefined;
        const name = String(token.meta?.name || '');
        const family = context?.model.fragments.find(item => item.name === name);
        const lookup = context && screenIndex(context.model, context.annotations);
        const base = lookup?.parts.get(family?.contributions[0] || '');
        const href = context && family && base ? screenHref(context.path, base.definition.path,
            family.target, context.format, context.destination) : undefined;
        return family ? screenLink(href, `Definition of ${name}`, token.content, family.target) :
            escapeHtml(token.content);
    };
}
export function installScreenPublicationLinks(md: MarkdownIt): void {
    const open = md.renderer.rules.link_open, close = md.renderer.rules.link_close;
    md.renderer.rules.link_open = (tokens, index, options, env, renderer) => {
        const token = tokens[index], href = token.attrGet('href') || '';
        const hash = href.indexOf('#');
        const reference = hash >= 0 ? parsePublicationReference(href.slice(hash + 1)) : undefined;
        if (!reference) { return open ? open(tokens, index, options, env, renderer)
            : renderer.renderToken(tokens, index, options); }
        const context = env?.literateScreen as ScreenAnnotationContext | undefined;
        const target = publicationReferenceTarget(reference);
        const document = href.slice(0, hash);
        let resolved: string | undefined;
        if (context && (!document || posix.normalize(posix.join(posix.dirname(context.path), document)) === context.path)) {
            resolved = context.format === 'preview' ? context.destination?.(target) : `#${target}`;
        } else if (context?.format === 'html' && document.endsWith('.literate')) {
            resolved = document.slice(0, -'.literate'.length) + `.html#${target}`;
        }
        token.meta = { ...(token.meta || {}), literatePublicationLink: !!resolved };
        return resolved ? `<a href="${escapeHtml(resolved)}" data-literate-target="${target}">`
            : '<span class="literate-publication-unresolved">';
    };
    md.renderer.rules.link_close = (tokens, index, options, env, renderer) => {
        let start = index - 1;
        while (start >= 0 && tokens[start].type !== 'link_open') { start--; }
        if (start >= 0) {
            const href = tokens[start].attrGet('href') || '', hash = href.indexOf('#');
            if (hash >= 0 && parsePublicationReference(href.slice(hash + 1))) {
                return tokens[start].meta?.literatePublicationLink ? '</a>' : '</span>';
            }
        }
        return close ? close(tokens, index, options, env, renderer) : renderer.renderToken(tokens, index, options);
    };
}
export function installScreenTermLinks(md: MarkdownIt): void {
    const open = md.renderer.rules.link_open, close = md.renderer.rules.link_close;
    const destination = (href: string, context?: ScreenAnnotationContext) => {
        if (!context) { return undefined; }
        const target = resolveTermHref(context.annotations, href);
        const at = target && screenIndex(context.model, context.annotations).targets.get(target)?.definition;
        return target && at ? { target, href: screenHref(context.path, at.path, target,
            context.format, context.destination) } : undefined;
    };
    md.renderer.rules.link_open = (tokens, index, options, env, renderer) => {
        const href = tokens[index].attrGet('href') || '';
        if (!href.startsWith('term:')) { return open ? open(tokens, index, options, env, renderer) : renderer.renderToken(tokens, index, options); }
        const link = destination(href, env?.literateScreen);
        const use = env?.literateUseTargets?.get(tokens[index]) as PublicationTermUse | undefined;
        const anchor = use ? `<span id="${screenTermUseTarget(use)}"${env.literateScreen?.format === 'preview' ? ` class="code-line" data-line="${use.at.line}"` : ''}></span>` : '';
        return anchor + (link?.href ? `<a href="${escapeHtml(link.href)}" data-literate-target="${link.target}">` : '<span class="literate-term-unresolved">');
    };
    md.renderer.rules.link_close = (tokens, index, options, env, renderer) => {
        let start = index - 1;
        while (start >= 0 && tokens[start].type !== 'link_open') { start--; }
        const href = start >= 0 ? tokens[start].attrGet('href') || '' : '';
        if (href.startsWith('term:')) { return destination(href, env?.literateScreen)?.href ? '</a>' : '</span>'; }
        return close ? close(tokens, index, options, env, renderer) : renderer.renderToken(tokens, index, options);
    };
}

Use anchors address model occurrences rather than matching label text. They are separate from definition identities and share the capability location map.

<<screen term use anchors>>=
function screenTermUseTarget(use: PublicationTermUse): string {
    const owner = use.owner.split('').map(char => char.charCodeAt(0).toString(16).padStart(4, '0')).join('');
    return `annotation-use-${owner}-${use.tokenIndex}-${use.childIndex}`;
}
export function screenTermUseAnchors(tokens: Token[], annotations: PublicationAnnotations, owner: string) {
    const anchors = new Map<Token, PublicationTermUse>();
    for (const use of annotations.uses) {
        if (use.owner !== owner) { continue; }
        const token = tokens[use.tokenIndex]?.children?.[use.childIndex];
        if (token?.type === 'link_open' && token.attrGet('href')?.startsWith('term:')) { anchors.set(token, use); }
    }
    return anchors;
}

Screen indexes

Only annotated books gain indexes. One root page owns both lists, with global navigation to definitions and accepted fragment contributions. Entries use titles and explicit semantic identities, not guessed identifiers or print page numbers.

<<screen book indexes>>=
export function renderScreenIndexes(context: ScreenAnnotationContext, paths: readonly string[]): string {
    const { model, annotations, path, format, destination } = context;
    if (!annotations.terms.length && !annotations.notes.length) { return ''; }
    if (path !== (paths.includes('index.literate') ? 'index.literate' : paths[0])) { return ''; }
    const lookup = screenIndex(model, annotations);
    const link = (target: string, title: string) => {
        const at = lookup.targets.get(target)?.definition;
        return screenLink(at && screenHref(path, at.path, target, format, destination), title, title, target);
    };
    const terms = annotations.terms.map(term => `<li>${link(term.target, term.title)} — Definition`
        + (lookup.termReferences.get(term.target) || []).map((use, index) =>
            ` · ${link(screenTermUseTarget(use), `Reference ${index + 1}`)}`).join('') + '</li>').join('');
    const fragments = model.fragments.map(family => `<li>${link(family.target, family.name)}: `
        + family.contributions.map((target, index) => link(target, index ? `Addition ${index}` : 'Definition')).join(' · ')
        + (lookup.fragmentReferences.get(family.target) || [])
            .map((part, index) => ` · ${link(part.target, `Reference ${index + 1}`)}`).join('') + '</li>').join('');
    return `<nav class="literate-screen-index" aria-label="Term index"><h2>Term index</h2><ul>${terms}</ul></nav>`
        + `<nav class="literate-screen-index" aria-label="Fragment index"><h2>Fragment index</h2><ul>${fragments}</ul></nav>`;
}
