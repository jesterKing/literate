Several publications in one workspace

A workspace used to imply one project. That default remains useful, but it cannot represent a series of independent books: recursive discovery would combine every fragment below the workspace root into one graph. Series support therefore begins with an explicit boundary model, before adding commands or cross-publication links.

The workspace manifest is data, not executable configuration. It names independent publication roots and enough metadata for hosts to present and publish them. The engine inside each root remains unchanged: paths, settings, fragments, templates, and outputs are still relative to that selected project.

Public contracts

The fixed manifest name makes discovery deterministic. Project roots and PDF outputs are normalized relative to the manifest, including parent traversal for layouts that keep series metadata beside a books directory. Entries remain strictly project-relative. Optional fields receive conservative defaults so the first schema can describe both a minimal project and a publication with a declared title, entry document, and PDF destination.

Validate bounded data

JSON parsing is only the first boundary. The accepted value must be a plain object with exactly the documented fields. IDs are short portable keys; titles reject control characters; paths use a portable slash-separated policy. Publication roots cannot overlap because recursive discovery in either root must never absorb another project. PDF destinations are manifest-relative and unique.

<<workspace project validation>>=
const identifier = /^[a-z0-9][a-z0-9._-]{0,99}$/;
const object = (value: unknown): value is Record<string, unknown> =>
    !!value && typeof value === 'object' && !Array.isArray(value) &&
    Object.getPrototypeOf(value) === Object.prototype;

function fields(value: Record<string, unknown>, allowed: readonly string[], label: string): void {
    const extra = Object.keys(value).filter(key => !allowed.includes(key));
    if (extra.length) { throw new Error(`${label} has unknown field: ${extra[0]}`); }
}

function text(value: unknown, label: string, maximum: number): string {
    if (typeof value !== 'string' || !value || value.length > maximum || /[\x00-\x1f\x7f]/.test(value)) {
        throw new Error(`${label} must be a nonempty string of at most ${maximum} characters`);
    }
    return value;
}

function projectPath(value: unknown, label: string): string {
    const input = text(value, label, 1024);
    const normalized = safeRelativePath(input);
    if (!normalized) { throw new Error(`${label} is not a safe project-relative path: ${input}`); }
    return normalized;
}

function manifestPath(value: unknown, label: string): string {
    const input = text(value, label, 1024);
    if (input.includes('\\') || input.startsWith('/') || /^[A-Za-z]:/.test(input)) {
        throw new Error(`${label} is not a portable manifest-relative path: ${input}`);
    }
    const components: string[] = [];
    for (const component of input.split('/')) {
        if (!component || component === '.') { continue; }
        if (component === '..') {
            if (components.length && components[components.length - 1] !== '..') { components.pop(); }
            else { components.push(component); }
        } else { components.push(component); }
    }
    const first = components.findIndex(component => component !== '..');
    const tail = first < 0 ? '' : components.slice(first).join('/');
    if (!tail || safeRelativePath(tail) !== tail) {
        throw new Error(`${label} is not a portable manifest-relative path: ${input}`);
    }
    return components.join('/');
}

const paperSizes: Record<PublicationProject['paper'], [number, number]> = {
    a4: [210, 297], a5: [148, 210], letter: [215.9, 279.4], legal: [215.9, 355.6]
};

function publicationPaper(value: unknown, label: string): PublicationProject['paper'] {
    const paper = value === undefined ? 'a4' : text(value, label, 20);
    if (!(paper in paperSizes)) { throw new Error(`${label} must be a4, a5, letter or legal`); }
    return paper as PublicationProject['paper'];
}

function publicationMargins(value: unknown, paper: PublicationProject['paper'], label: string): PublicationMargins {
    if (value === undefined) { return { top: 20, outer: 20, bottom: 20, inner: 20 }; }
    if (!object(value)) { throw new Error(`${label} must be an object`); }
    fields(value, ['top', 'outer', 'bottom', 'inner'], label);
    const margins: PublicationMargins = { top: 0, outer: 0, bottom: 0, inner: 0 };
    for (const side of ['top', 'outer', 'bottom', 'inner'] as const) {
        const margin = value[side];
        if (typeof margin !== 'number' || !Number.isFinite(margin) || margin < 5 || margin > 50) {
            throw new Error(`${label} ${side} must be a number from 5 to 50 mm`);
        }
        margins[side] = margin;
    }
    const [width, height] = paperSizes[paper];
    if (width - margins.outer - margins.inner < 80 || height - margins.top - margins.bottom < 100) {
        throw new Error(`${label} must leave at least an 80 × 100 mm body for ${paper}`);
    }
    return margins;
}

function collision(left: string, right: string): boolean {
    const a = left.toLowerCase(), b = right.toLowerCase();
    return a === b || a.startsWith(b + '/') || b.startsWith(a + '/');
}

Parsing copies accepted values into fresh records. This prevents callers from retaining mutable JSON objects as configuration state. Encounter order remains the manifest's publication order and is used by selectors and future project pickers.

export function parsePublicationWorkspace(source: string): PublicationWorkspace {
    if (source.length > 1024 * 1024) { throw new Error('Workspace manifest exceeds 1 MiB'); }
    let parsed: unknown;
    try { parsed = JSON.parse(source); }
    catch (error) { throw new Error(`Invalid workspace manifest JSON: ${error instanceof Error ? error.message : String(error)}`); }
    if (!object(parsed)) { throw new Error('Workspace manifest must be an object'); }
    fields(parsed, ['schemaVersion', 'publications'], 'Workspace manifest');
    if (parsed.schemaVersion !== 1) { throw new Error('Workspace manifest schemaVersion must be 1'); }
    if (!Array.isArray(parsed.publications) || !parsed.publications.length || parsed.publications.length > 1000) {
        throw new Error('Workspace manifest publications must contain 1 to 1000 entries');
    }
    const publications = parsed.publications.map((value, index): PublicationProject => {
        const label = `Publication ${index + 1}`;
        if (!object(value)) { throw new Error(`${label} must be an object`); }
        fields(value, ['id', 'title', 'root', 'entry', 'pdf', 'paper', 'margins'], label);
        const id = text(value.id, `${label} id`, 100);
        if (!identifier.test(id)) { throw new Error(`${label} id is invalid: ${id}`); }
        const root = manifestPath(value.root, `${label} root`);
        const title = value.title === undefined ? id : text(value.title, `${label} title`, 200);
        const entry = value.entry === undefined ? 'index.literate' : projectPath(value.entry, `${label} entry`);
        const pdf = value.pdf === undefined ? undefined : manifestPath(value.pdf, `${label} pdf`);
        const paper = publicationPaper(value.paper, `${label} paper`);
        const margins = publicationMargins(value.margins, paper, `${label} margins`);
        if (!entry.endsWith('.literate')) { throw new Error(`${label} entry must end in .literate`); }
        if (pdf !== undefined && !pdf.endsWith('.pdf')) { throw new Error(`${label} pdf must end in .pdf`); }
        return { id, title, root, entry, ...(pdf === undefined ? {} : { pdf }), paper, margins };
    });
    for (let index = 0; index < publications.length; index++) {
        const current = publications[index];
        for (let earlier = 0; earlier < index; earlier++) {
            const previous = publications[earlier];
            if (current.id.toLowerCase() === previous.id.toLowerCase()) {
                throw new Error(`Publication id conflicts with ${previous.id}: ${current.id}`);
            }
            if (collision(current.root, previous.root)) {
                throw new Error(`Publication root overlaps ${previous.root}: ${current.root}`);
            }
            if (current.pdf && previous.pdf && current.pdf.toLowerCase() === previous.pdf.toLowerCase()) {
                throw new Error(`Publication PDF conflicts with ${previous.pdf}: ${current.pdf}`);
            }
        }
    }
    return { schemaVersion: 1, publications };
}

Select one isolated project

A manifest with one project needs no extra selector. A series with several projects requires an explicit ID unless a host can select by active source path. Errors list the available IDs so command-line and editor users can recover without inspecting internal state.

export function selectPublication(workspace: PublicationWorkspace, id?: string): PublicationProject {
    if (id === undefined) {
        if (workspace.publications.length === 1) { return workspace.publications[0]; }
        throw new Error(`Select a publication: ${workspace.publications.map(item => item.id).join(', ')}`);
    }
    const selected = workspace.publications.find(item => item.id === id);
    if (!selected) {
        throw new Error(`Unknown publication ${id}; available publications: ${workspace.publications.map(item => item.id).join(', ')}`);
    }
    return selected;
}

export function publicationForPath(workspace: PublicationWorkspace,
    manifestPathname: string): PublicationProject | undefined {
    let normalized: string;
    try { normalized = manifestPath(manifestPathname, 'Document path'); }
    catch { return undefined; }
    return workspace.publications.find(item => normalized === item.root || normalized.startsWith(item.root + '/'));
}

This module deliberately performs no filesystem access. CLI and editor adapters must canonicalize the workspace, read the fixed manifest safely, verify selected roots on disk, and only then discover project inputs. Keeping those effects in the hosts lets the same strict selection policy serve saved CLI input and unsaved editor snapshots.
