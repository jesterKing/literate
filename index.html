Publication settings

The root settings below make our current defaults explicit. The theme applies to preview, HTML and LaTeX; font selection currently applies only to LaTeX books. Change any font family independently: font-body selects prose, font-heading selects headings, font-code selects code, font-fragment selects fragment names and references, and font-note selects running matter and reference page numbers. Omit font-note to inherit font-body; specifying it fixes that role independently. Use font-code-ligatures=off to disable contextual code ligatures.

Font values are family names, not file paths. Selecting a family does not install it: make it available to the TeX compiler, or explicitly provide its faces and licenses with the CLI's --font-manifest option. Chapter-local settings do not override these root font choices. See Publication font settings and Portable font companions for details.
